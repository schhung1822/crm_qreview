# 사용 안내서

이 문서는 소프트웨어를 처음부터 끝까지 사용하는 방법을 안내합니다. 계정을 새로 만드는 것부터 SEO/GEO에 맞는 글을 작성하고, 웹사이트에 글을 게시하는 것까지 다룹니다. 기술적인 지식이 전혀 없어도 그대로 따라 하실 수 있습니다.

> 팁: 페이지 상단의 "안내서에서 찾기" 칸을 사용하면 원하는 부분으로 빠르게 이동할 수 있습니다.

> 사용 중 (i) 아이콘이 있는 곳을 클릭하면 해당 항목의 자세한 설명을 볼 수 있습니다.

---

## 1. 빠른 시작 (3단계)

단 3단계만으로 첫 번째 글을 완성할 수 있습니다:

1. **AI의 API 키 입력** - 이 소프트웨어는 글을 작성하고 채점하기 위해 AI(Claude, OpenAI, Gemini, DeepSeek)를 사용합니다. 한 개 공급업체의 API 키를 **연결** 메뉴에 붙여넣어야 합니다(3번 참고).
2. **웹사이트 연결**(지금 바로 하지 않아도 됩니다) - WordPress, Wix, Shopify, Haravan, Sapo 또는 Google Sheet에 글을 바로 게시하고 싶다면 **연결** 메뉴에서 연결을 추가하세요.
3. **첫 번째 글 작성** - **편집기**로 이동해 주제를 입력하고, AI가 초안을 만들도록 한 다음 수정하고 채점합니다.

**대시보드** 페이지에는 1번과 2번 단계를 완료하도록 안내하는 체크리스트가 준비되어 있습니다. 완료하면 체크리스트는 자동으로 사라집니다.

---

## 2. 기본 개념

- **조직(Biz)**: 여러분의 작업 공간입니다. 모든 글, 연결, 직원은 하나의 조직에 속합니다. 여러 개의 조직을 만들 수 있으며, 왼쪽 메뉴 상단의 조직 이름 선택 칸으로 서로 전환할 수 있습니다.
- **글(Article)**: 여러분이 작성하는 하나의 콘텐츠입니다. 글에는 **초안**(draft) 또는 **게시됨**(published) 상태가 있습니다.
- **SEO / AEO / GEO 점수**: 글 품질을 나타내는 세 가지 척도입니다:
  - **SEO**: 검색 엔진(Google)에 대한 최적화 정도입니다 - 제목, 설명, 헤딩 태그, 키워드, 링크.
  - **AEO**: Google AI Overviews와 같은 답변 상자(Answer Engine)에 노출되도록 하는 최적화 정도입니다.
  - **GEO**: AI(ChatGPT, Perplexity, Gemini)가 여러분의 글을 인용하도록 하는 최적화 정도입니다.
- **token**: AI가 처리하는 글자 양을 측정하는 단위입니다. "입력 token"은 여러분이 AI에게 보내는 데이터이고, "출력 token"은 AI가 생성하는 내용입니다. AI 비용은 token을 기준으로 계산되며, 자세한 내용은 **리포트**에서 확인할 수 있습니다.
- **연결(Connection)**: 글을 게시할 웹사이트/채널(WordPress, Wix, Shopify, Haravan, Sapo, Google Sheet)로의 연결입니다.

---

## 3. 연결: AI API 키와 웹사이트

이곳은 소프트웨어가 작동하는 데 필요한 모든 것을 등록하는 곳입니다. 왼쪽 메뉴(**시스템** 그룹)에서 **연결** 메뉴를 여세요.

### 3.1. AI의 API 키 추가

이 소프트웨어에는 AI가 기본으로 포함되어 있지 않습니다 - 여러분 자신의 API 키를 사용하므로 비용과 한도를 직접 관리할 수 있습니다.

1. **연결** → **AI API 키** 영역으로 이동합니다.
2. 공급업체를 선택합니다: **Claude (Anthropic)**, **OpenAI**, **Gemini (Google)** 또는 **DeepSeek**.
3. API 키(해당 공급업체의 관리 페이지에서 가져옴)를 붙여넣고 **저장**합니다.
4. 스위치를 켜서 활성화합니다. 여러 공급업체를 추가하고 주로 사용할 것을 선택할 수 있습니다.

> 팁: 키가 아직 없다면 AI 공급업체에서 계정을 등록하고 API 키를 만든 다음 돌아와서 붙여넣으세요. 키는 안전하게 저장되며, 저장한 후에는 전체가 다시 표시되지 않습니다.

### 3.2. 글 게시를 위한 웹사이트 연결

1. **연결** → **웹사이트 연결** 영역 → **연결 추가**로 이동합니다.
2. 플랫폼을 선택합니다: **WordPress, Wix, Shopify, Haravan, Sapo**.
3. 각 플랫폼에 맞게 창에 바로 표시되는 안내를 따르세요(사이트 주소, 계정/애플리케이션 비밀번호 또는 token 입력).
4. **연결 확인**을 눌러 정보가 올바른지 확인한 다음 **저장**합니다.

연결한 후에는 소프트웨어에서 바로 글을 게시하거나 업데이트할 수 있습니다(11번 참고).

---

## 4. 키워드 조사

**키워드** 메뉴는 글을 쓰기 전에 키워드를 찾고 그룹화하여, 검색하는 사람의 요구에 맞는 글을 쓸 수 있도록 도와줍니다.

1. **키워드**로 이동해 기본 키워드를 입력합니다(예: "러닝화").
2. 소프트웨어가 검색 의도와 자주 묻는 질문(GEO 형태)과 함께 관련 키워드 세트를 제안합니다.
3. 적합한 키워드를 선택하고 키워드 세트로 저장하여 계획 단계에서 사용합니다.

> 팁: 의도(intent) 열에 주목하세요. "구매/가격" 키워드는 판매용 글에 적합하고, "방법/무엇" 키워드는 안내용 글에 적합합니다.

---

## 5. 콘텐츠 계획 세우기

**계획** 메뉴는 키워드 세트를 작성해야 할 글 목록으로 바꿔 주며, 제목과 추천 개요를 제공합니다.

1. **계획**으로 이동해 키워드 세트를 선택하거나 주제를 입력합니다.
2. 소프트웨어가 글 제목(title)과 개요를 제안합니다.
3. 검토하고 수정한 다음, 각 항목을 **편집기**로 옮겨 작성합니다.

이 방식은 흩어진 글을 쓰는 대신 체계적으로 콘텐츠 클러스터(topic cluster)를 구축하는 데 도움이 됩니다.

---

## 6. 편집기 (글 작성)

**편집기** 메뉴는 글을 작성하고 완성하는 곳입니다.

1. **제목**과 **목표 키워드**를 입력합니다.
2. 버튼을 눌러 AI가 주제에 맞는 **초안**을 만들도록 합니다. 직접 작성하거나 기존 내용을 붙여넣을 수도 있습니다.
3. 다음 지원 도구를 사용합니다:
   - 문단을 **다시 쓰기 / 확장 / 축약**.
   - **자연스럽게 다듬기(humanize)**: 문장을 자연스럽게 만들고 기계적인 어투를 줄입니다.
   - **사실 확인(fact-check)**: 틀리기 쉬운 정보를 점검합니다.
   - **삽화 이미지 넣기**: 이미지를 생성하거나 이미지를 추천합니다(10번 참고).
4. **SEO / AEO / GEO** 점수가 바로 업데이트되는 것을 확인하고, 제안을 따라 점수를 높이세요.
5. **저장**을 누르면 글이 초안 상태로 **글** 목록에 들어갑니다.

> 팁: 제목에 주요 키워드를 포함하고, 명확한 헤딩으로 글을 나누며, 첫 문단에서 질문에 바로 답하세요 - 이 세 가지는 모두 SEO와 GEO 모두에 좋습니다.

---

## 7. 글 관리

**글** 메뉴는 조직 내 모든 글을 나열합니다.

- **상태**(초안 / 게시됨)와 **언어**로 필터링합니다.
- 글을 열어 **이어서 수정**, **다시 채점**, **번역**, **최적화** 또는 **게시**를 할 수 있습니다.
- 점수 열을 통해 어떤 글을 개선해야 할지 빠르게 확인할 수 있습니다.

> 참고: 이미 게시된 글을 수정한 후 다시 게시하면, 같은 연결을 통해 게시하는 한 소프트웨어가 **웹사이트의 원래 글을 정확히 업데이트**합니다(중복 글을 만들지 않습니다).

---

## 8. SEO와 GEO 최적화

**최적화** 메뉴는 상세하게 채점하고 정확히 어디를 수정해야 하는지 알려 줍니다.

1. 최적화할 글을 선택합니다.
2. 각 기준별 점수표를 확인합니다: 제목, 설명(meta), 헤딩 구조, 키워드 밀도, 내부 링크, 구조화된 데이터(schema), AI 인용 가능성 등.
3. "미달"인 각 항목에는 구체적인 제안이 있습니다. 제안을 적용한 다음 점수가 높아질 때까지 다시 채점하세요.

**내부 링크에 대하여**: **실제로 게시된**(실제 주소가 있는) 글에만 링크하는 것이 좋습니다. 아직 존재하지 않는 페이지로 링크를 걸지 마세요.

**외부 링크에 대하여**: 다른 웹사이트로 나가는 모든 링크는 독자가 여러분의 페이지를 떠나지 않도록 새 탭에서 열리게 하는 것이 좋습니다.

---

## 9. 번역과 다국어

**번역** 메뉴는 한 글의 다른 언어 버전을 만드는 데 도움을 줍니다.

1. 원본 글과 대상 언어를 선택합니다.
2. 소프트웨어는 기계적으로 번역하지 않고 **현지화**합니다: 예시, 단위, 문체를 맞춘 다음 현지 키워드에 맞게 SEO/GEO를 다시 최적화합니다.
3. 번역본을 다시 검토하고 필요하면 수정한 다음 별도의 글로 저장합니다.

소프트웨어 화면은 여러 언어를 지원하며, 표시 언어는 계정 메뉴에서 변경합니다.

---

## 10. 이미지: 설정과 압축

### 10.1. 이미지 설정 (삽화 이미지)

**이미지 설정** 메뉴는 글에 이미지를 생성하고 삽입하는 방식을 정합니다: 스타일, 비율, SEO를 위한 대체 텍스트(alt).

### 10.2. 이미지 압축

**이미지 압축** 메뉴는 이미지 용량을 줄이고 형식을 **WebP/AVIF**(SEO에 친화적이고 더 빠르게 로딩됨)로 바꾸는 데 도움을 줍니다.

1. 이미지를 업로드합니다.
2. 형식과 압축 수준을 선택합니다.
3. 최적화된 이미지를 다운로드합니다. 소프트웨어는 직접 처리하며 여러분의 이미지를 저장하지 않습니다.

---

## 11. 글 게시하기

### 11.1. CMS에 게시 (WordPress, Wix, Shopify, Haravan, Sapo)

1. **게시**로 이동합니다(또는 글을 열고 게시를 선택합니다).
2. 대상 웹사이트 **연결**을 선택합니다.
3. 제목, 주소(slug), 설명, 표지 이미지를 확인합니다.
4. **게시**를 누릅니다. 이전에 게시한 글이라면 소프트웨어가 원래 글을 정확히 **업데이트**합니다.

### 11.2. Google Sheet에 게시

CMS 외에도 글을 **Google Sheet**에 넣을 수 있습니다(예: 다른 팀이 이어서 처리하도록). Google을 한 번 연결하고 대상 스프레드시트를 선택하면, 소프트웨어가 각 글을 행 단위로 기록하고 slug에 따라 업데이트합니다.

### 11.3. 게시 일정

**캘린더** 메뉴에서는 게시 일정을 잡을 수 있습니다: 각 글에 날짜와 시간을 지정해 한꺼번에 게시하는 대신 콘텐츠가 꾸준히 나가도록 합니다.

---

## 12. 검사와 점검

- **점검**: 한 페이지/글을 스캔하여 SEO 상태를 채점하고 수정해야 할 오류를 알려 줍니다.
- **랜딩 점검(Landing Audit)**: 판매/랜딩 페이지만 따로 살펴보며 제목, 행동 유도 문구, 설득 구조를 평가합니다.

이 메뉴들을 사용해 이미 있는 콘텐츠(소프트웨어로 만들지 않은 글 포함)를 다시 점검하세요.

---

## 13. 리포트와 인용

- **리포트**: 사용한 token 양, AI 비용(여러분의 통화로 환산), 공급업체/모델별 및 직원별 통계를 확인합니다. 비용 관리에 사용하세요.
- **인용(Citations)**: 글에 인용할 신뢰할 수 있는 출처를 제안하여, 신뢰도와 AI 인용 가능성(GEO)을 높이는 데 도움을 줍니다.

---

## 14. 작업과 협업

조직에 여러 사람이 있다면 **내 작업** 메뉴를 사용해 팀으로 작업하세요:

- **글 배정**: 소유자/관리자가 직원에게 작성할 글을 배정합니다.
- **글 승인**: 글은 게시 전에 권한이 있는 사람의 **승인**을 받아야 합니다. 여러분이 승인할 글은 **내 작업**에 표시됩니다.
- **댓글**: 각 글에서 바로 소통합니다.

권한 설정(누가 작성, 게시, 승인, 연결 관리를 할 수 있는지 등)은 **조직** 페이지에서 합니다(17번 참고).

---

## 15. 소식과 알림

- **알림 벨**(상단 모서리): 여러분에게 전달되는 업데이트와 알림입니다.
- **소식**: 소프트웨어 관련 뉴스와 사용 팁입니다. **새** 소식에는 "새로움" 라벨이 붙으며, 소식을 열어 읽으면 해당 소식의 라벨이 사라집니다. **모두 읽음으로 표시** 버튼으로 빠르게 지울 수 있습니다.

---

## 16. 요금제와 한도

**요금제** 메뉴에서는 현재 어떤 요금제를 사용 중인지, 이번 기간에 글 작성 횟수가 얼마나 남았는지, 그리고 갱신일을 알 수 있습니다.

- 남은 한도와 이력을 확인합니다.
- 더 많은 한도나 기능이 필요할 때 요금제를 업그레이드합니다.
- 계정에 추가 횟수(overage)나 무제한이 부여된 경우 해당 정보도 여기에 표시됩니다.

---

## 17. 계정, 보안, 조직

### 17.1. 계정

**계정** 메뉴(메뉴 하단의 이름을 클릭)에서는 표시 이름을 바꾸고 **비밀번호를 변경**할 수 있습니다. 비밀번호를 잊었다면 로그인 페이지의 "비밀번호 찾기" 링크를 사용해 이메일로 재설정하세요.

### 17.2. 조직 (Biz)

메뉴 상단의 조직 이름을 클릭 → **조직 관리**:

- **직원**: 조직에 사람을 초대하고 역할에 따라 권한을 부여합니다.
- **브랜드 보이스(Brand voice)**: AI가 브랜드 특성에 맞게 쓰도록 문체를 등록합니다.
- **조직 API token**: 다른 시스템이 여러분의 API를 호출할 수 있도록 키를 만듭니다(개발자용).
- **조직 전환/새로 만들기**: 여러 작업 공간을 관리합니다.

## 18. 자주 묻는 질문 (FAQ)

**AI API 키가 반드시 있어야 하나요?**
네. 글 작성과 채점 기능은 AI를 사용하므로, 연결 메뉴에 유효한 API 키가 최소 한 개는 필요합니다.

**왜 아직 글을 게시할 수 없나요?**
다음을 확인하세요: 웹사이트 연결을 추가했는지, 연결 정보가 여전히 올바른지(연결 확인을 누르세요), 그리고 계정에 **게시** 권한이 있는지.

**게시한 글을 수정한 후 다시 게시하면 중복 글이 생기나요?**
아니요. 같은 연결을 통해 게시하면 소프트웨어가 원래 글을 정확히 업데이트합니다.

**SEO/GEO 점수가 낮으면 어디서 고치나요?**
**최적화** 메뉴로 가세요: 미달인 각 기준마다 구체적인 제안이 있어 수정한 후 다시 채점할 수 있습니다.

**AI 비용은 어떻게 계산되나요?**
여러분이 사용하는 공급업체의 입력/출력 token에 따라 계산됩니다. 자세한 내용은 **리포트**에서 확인하세요.

**여러 사람이 함께 작업하고 싶어요.**
그들을 **조직**에 초대하고 권한을 부여하세요. **내 작업**에서 글 배정 - 글 승인 흐름을 사용하세요.

**화면 언어는 어디서 바꾸나요?**
계정 메뉴/언어 선택에서 바꿉니다. 글 내용의 번역은 **번역** 메뉴에서 별도로 합니다.

## 19. 소셜·이커머스 리포트(Facebook·Instagram·Threads·TikTok·YouTube·FB 그룹·Shopee·TikTok Shop·Lazada)

실제 데이터 + AI로 소셜 채널(내 것 또는 경쟁사)을 2단계로 분석합니다:

1. **연결 관리** → 소셜 리포트용 **데이터 수집** 키 추가(그곳 안내를 따르세요). 수집마다 결과 수에 따라 크레딧(보통 몇 센트)이 소모됩니다. **여러 Apify 키**를 추가할 수 있습니다 - 저장 전에 키를 확인하며, 수집마다 무작위로 키 하나를 사용합니다(실패하거나 한도를 초과한 키는 자동으로 다른 키로 전환).
2. **소셜 리포트** → **리포트 만들기** → 팝업에서 **채널 선택**: Facebook 페이지, TikTok, YouTube 또는 **종합**(멀티 플랫폼). 종합은 2가지 방식: **키워드/주제** 입력(플랫폼별 인기 콘텐츠 자동 수집) 또는 **채널 링크** 직접 입력.
3. **1단계 - 원시 데이터 수집**: 진행률과 함께 단계별 실행(채널 정보 → 게시물/동영상 → Facebook은 Reels/광고 → 댓글) 후 **수집 완료**에서 정지 - 채널별 원시 데이터 + 지표를 바로 확인.
4. **2단계 - AI 분석**: **분석** 클릭 → AI와 모델 선택(또는 "자동") → 브랜드·전술·요약 분석; 종합 리포트에는 **채널 간 비교**와 배분 제안 추가. 다른 AI로 **다시 분석**해도 추가 수집 비용 없음.
5. 리포트 목록은 채널별 필터 가능; 시스템에서 보기, **PDF 내보내기**, **.doc 다운로드**, **Google Drive 저장**(로고 + 출처는 시스템 정보).

6. **브랜드 스타일**: 리포트 페이지에서 **브랜드 스타일** 클릭 → AI가 게시물/동영상에서 스타일 프로필(톤, 호칭, 어휘, 문장 패턴, 논증, 공식, 고유 특징, 시그니처 문구, 해야/피해야)을 추출 → 섹션별로 확인하고 **Markdown 복사/다운로드** 또는 **재사용 프롬프트 복사**로 다른 AI가 이 브랜드 목소리로 쓰게 할 수 있습니다.

7. **Facebook 그룹 리포트**: 생성 팝업에서 **Facebook 그룹**을 선택하고 **공개** 그룹 링크(facebook.com/groups/...)를 붙여넣으세요. 시스템이 **게시물과 각 게시물의 댓글**(댓글은 게시물에 붙어 함께 분석), 그룹 정보(멤버 수, 설명), 지표(게시 빈도, 게시물 유형, 주요 기여 멤버)를 수집합니다. AI가 커뮤니티 관점에서 **핫한 주제**, **멤버 인사이트**(니즈, 페인포인트, 질문, 언어), **콘텐츠/시딩 기회**와 게시물 아이디어를 분석합니다. 게시물 범위는 **인기**(최근 6개월 참여도 상위) 또는 **최신** 중 선택할 수 있습니다. 비공개 그룹은 분석할 수 없습니다.

8. **Instagram / Threads / Shopee 상품**: 생성 팝업에서 해당 채널을 선택하세요. Instagram은 프로필 링크 또는 @username(게시물 + Reels(**자막** 포함) + 댓글), Threads는 @username(게시물 + 답글, 리포스트/인용 지표), Shopee는 **상품 링크**(...-i.SHOPID.ITEMID)를 붙여넣습니다 - 시스템이 상품 정보 + 구매자 리뷰(항목별 별점, 구매 옵션, 판매자 답변 포함)를 수집하고 AI가 **리스팅**, **구매자 인사이트**(칭찬/불만, 니즈, 언어), **개선 제안 + 판매 콘텐츠 + FAQ**를 분석합니다. Instagram과 Threads는 종합 리포트에도 참여할 수 있습니다.

9. **Shopee 샵**: **Shopee 샵**을 선택하고 샵 링크(예: shopee.vn/shopname) 또는 사용자명을 붙여넣으세요. 시스템이 **샵 정보**(별점, 팔로워, 총 상품 수, 응답률) + **상품 카탈로그**(가격, 할인, 평점) + **인기 상품 리뷰**(리뷰는 각 상품에 연결)를 수집하고, AI가 **카탈로그·가격 전략**, **상품 횡단 고객 인사이트**, **요약·제안**(기회, 개선, 판매 콘텐츠)을 분석합니다. 상품 보고서처럼 보고서 이름을 지정할 수 있습니다.

10. **TikTok Shop**: **TikTok Shop** 카드(및 **Shopee** 카드)는 두 유형을 통합 - 클릭하면 **상품**과 **샵 전체** 중 선택합니다. 상품: 상품 링크(또는 vt.tiktok.com 공유 링크/상품 ID) 붙여넣기 → 가격, 할인, **판매량**, 재고, 옵션 + 고객 리뷰 수집 → AI가 리스팅 분석, 구매자 인사이트, **판매 영상** 제안. 샵: TikTok Shop 표시 그대로 **샵 이름** 입력(공개 샵 URL 없음) → 샵의 인기 상품 + 총 판매량/추정 매출 + 인기 상품 리뷰(상품별 연결) 수집 → AI가 카탈로그·가격, 고객 인사이트, 요약 분석. **지역**을 올바르게 선택하세요(기본 VN).

11. **Lazada**: **Lazada** 카드도 두 유형을 통합. 상품: 경로에 상품명이 포함된 전체 링크(또는 s.lazada.vn 공유 링크) 붙여넣기 → 한 번의 실행으로 가격, 할인, **판매량**, 판매자 + 고객 리뷰 수집 → AI가 리스팅, 구매자 인사이트, 요약 분석. 샵: 샵 링크(lazada.vn/shop/shopname) 붙여넣기 → 카탈로그 + 상품별 리뷰 수집 → AI가 카탈로그·가격, 고객, 요약 분석.

12. **이커머스 종합**(시장조사): **종합** 카드가 이제 **소셜**(기존 흐름)과 **이커머스** 중 선택을 묻습니다. 이커머스: **상품/니치 키워드** + 지역 입력 → Shopee, TikTok Shop, Lazada의 **베스트셀러** 수집 → AI가 **시장 그림**(수요, 마켓별 가격), **마켓 횡단 주요 경쟁사**, **요약 + 진입 계획**(우선 마켓, 제안 가격, 차별화)을 분석. 판매 전 시장/경쟁사 조사에 활용하세요.

13. **시각화 차트**: 모든 보고서는 **차트** 섹션으로 시작합니다 - 소셜: 게시 시점별 성과, 톱 게시물, 형식, 요일(FB 그룹은 활발한 멤버 추가); 상품: 별점 분포, 인기 옵션; 샵: 베스트셀러, 가격 분포, 별점 분포(TikTok Shop은 **7 vs 30일 판매 속도**를 증감에 따라 녹/적 표시); 종합: 채널/마켓 비교 차트. PDF/.doc/Drive 내보내기에서도 차트가 유지됩니다.

14. **출시 예정**: **Zalo**와 **Messenger** 채널은 개발 중입니다 - 채널 선택 목록에 "Coming soon" 태그로 표시되며 아직 선택할 수 없습니다. 준비되면 활성화됩니다.

요금제 제한: 월별 소셜 리포트 생성 횟수와 사용 가능한 채널은 계정 소유자의 요금제에 따라 다릅니다. Free 요금제는 Facebook 페이지만 분석할 수 있습니다. 현재 한도는 **요금제** 페이지에서 확인하세요. Free 요금제에서는 페이지 리포트가 앞부분(타깃 고객까지)만 표시되고 PDF/DOC/Drive로 내보낼 수 없습니다 - 업그레이드하면 전체 분석과 내보내기가 열립니다.

팁: 게시물은 채널별 "게시물 1..N"으로 참조(여러 채널이면 플랫폼명 포함); 중간 실패 시 **다시 시도**로 이어서 실행.

# 使用指南

本文档手把手教你从头到尾使用本软件：从刚创建账户、撰写符合 SEO/GEO 标准的文章，一直到把文章发布到网站。即使你完全不懂技术，也能照着做。

> 提示：使用页面顶部的"在指南中搜索"输入框，可以快速跳转到你需要的部分。

> 使用过程中，凡是看到 (i) 图标，点击即可阅读该字段的详细说明。

---

## 1. 快速开始（3 步）

只需 3 步，你就能完成第一篇文章：

1. **填入 AI 的 API 密钥** - 本软件使用 AI（Claude、OpenAI、Gemini、DeepSeek）来撰写和评分。你需要把某个提供商的 API 密钥粘贴到**连接**页（见第 3 部分）。
2. **连接网站**（不必立即完成）- 如果你想把文章直接发布到 WordPress、Wix、Shopify、Haravan、Sapo 或 Google Sheet，请在**连接**页中添加连接。
3. **撰写第一篇文章** - 进入**编辑器**，输入主题，让 AI 生成草稿，然后修改并评分。

**概览**页中已经准备好一份检查清单（checklist），提醒你完成第 1 步和第 2 步。完成后，检查清单会自动隐藏。

---

## 2. 基本概念

- **组织（Biz）**：你的工作空间。所有文章、连接、成员都属于某个组织。你可以创建多个组织，并通过左侧菜单栏顶部的组织名称选择框在它们之间切换。
- **文章（Article）**：你撰写的一篇内容。文章有**草稿**（draft）或**已发布**（published）两种状态。
- **SEO / AEO / GEO 分数**：衡量文章质量的三个指标：
  - **SEO**：对搜索引擎（Google）的优化程度 - 标题、描述、heading 标签、关键词、链接。
  - **AEO**：进入答案框（Answer Engine，如 Google AI Overviews）的优化程度。
  - **GEO**：被各类 AI（ChatGPT、Perplexity、Gemini）引用你文章的优化程度。
- **token**：衡量 AI 处理文字量的单位。"输入 token"是你发送给 AI 的数据，"输出 token"是 AI 生成的内容。AI 的费用按 token 计算；详情见**报表**。
- **连接（Connection）**：连到某个网站/渠道以发布文章（WordPress、Wix、Shopify、Haravan、Sapo、Google Sheet）。

---

## 3. 连接：AI 的 API 密钥和网站

这里是配置软件运行所需一切的地方。打开左侧菜单栏中的**连接**（位于**系统**分组）。

### 3.1. 添加 AI 的 API 密钥

本软件不自带 AI - 你使用自己的 API 密钥，因此能自主掌控费用和额度。

1. 进入**连接** → **AI API 密钥**区域。
2. 选择提供商：**Claude (Anthropic)**、**OpenAI**、**Gemini (Google)** 或 **DeepSeek**。
3. 粘贴 API 密钥（从对应提供商的管理页获取）并**保存**。
4. 打开开关以启用。你可以添加多个提供商，并选择主用的那个。

> 提示：如果还没有密钥，请到 AI 提供商处注册账户，创建 API key，再回来粘贴。密钥会被安全保存，保存后不会再完整显示。

### 3.2. 连接网站以发布文章

1. 进入**连接** → **网站连接**区域 → **添加连接**。
2. 选择平台：**WordPress、Wix、Shopify、Haravan、Sapo**。
3. 按照窗口中针对各平台即时显示的说明操作（填入站点地址、账户/应用密码或 token）。
4. 点击**测试连接**以确认信息无误，然后**保存**。

连接完成后，你就可以直接从软件发布或更新文章（见第 11 部分）。

---

## 4. 关键词研究

**关键词**页帮你在撰写前找到并归组关键词，让文章契合搜索者的需求。

1. 进入**关键词**，输入一个种子关键词（例如："跑步鞋"）。
2. 软件会推荐相关关键词组，附带搜索意图和常见问题（GEO 形式）。
3. 选择合适的关键词并保存为关键词组，供规划步骤使用。

> 提示：注意意图（intent）这一列。"购买/价格"类关键词适合销售型文章；"如何/是什么"类关键词适合指南型文章。

---

## 5. 内容规划

**规划**页把关键词组变成需要撰写的文章列表，附带标题和建议大纲。

1. 进入**规划**，选择关键词组或输入主题。
2. 软件会建议若干篇文章标题（title）和大纲（outline）。
3. 审阅、修改后，把每一项转到**编辑器**中撰写。

这种方式帮你系统地搭建内容集群（topic cluster），而不是零散地写作。

---

## 6. 编辑器（撰写文章）

**编辑器**页是你撰写和完善文章的地方。

1. 输入**标题**和**目标关键词**。
2. 点击让 AI 按主题生成**草稿**。你也可以自己撰写或粘贴现成内容。
3. 使用辅助工具：
   - **改写 / 扩展 / 精简**段落。
   - **人性化（humanize）**：让文字更自然，减少机器味。
   - **事实核查（fact-check）**：检查容易出错的信息。
   - **插入配图**：生成图片或推荐图片（见第 10 部分）。
4. 实时查看 **SEO / AEO / GEO** 分数，并按建议提升分数。
5. 点击**保存** - 文章会以草稿状态进入**文章**列表。

> 提示：标题中包含主关键词，用清晰的 heading 分隔文章，并在开头段落直接回答问题 - 这三点对 SEO 和 GEO 都有好处。

---

## 7. 管理文章

**文章**页列出组织内的所有文章。

- 按**状态**（草稿 / 已发布）和**语言**筛选。
- 打开某篇文章可**继续编辑**、**重新评分**、**翻译**、**优化**或**发布**。
- 分数列帮你快速看出哪篇文章需要改进。

> 注意：当你修改一篇已发布的文章后再次发布时，只要你通过同一个连接发布，软件会**在网站上正确更新原文章**（不会创建重复文章）。

---

## 8. SEO 和 GEO 优化

**优化**页进行详细评分，并精确指出需要修改的地方。

1. 选择要优化的文章。
2. 查看按各项标准的评分表：标题、描述（meta）、heading 结构、关键词密度、内部链接、结构化数据（schema）、被 AI 引用的可能性……
3. 每个"未达标"项都有具体建议。应用建议后再次评分，直到分数变高。

**关于内部链接**：只应链接到**真正已发布**的文章（有真实路径）。不要放指向尚不存在的页面的链接。

**关于外部链接**：所有指向其他网站的链接都应在新标签页打开，以免读者离开你的页面。

---

## 9. 翻译与多语言

**翻译**页帮你创建一篇文章的其他语言版本。

1. 选择原文章和目标语言。
2. 软件不做生硬的机器翻译，而是**本地化**：适配示例、单位、文风，再按本地关键词重新优化 SEO/GEO。
3. 复核译文，如有需要则修改，然后作为独立文章保存。

软件界面支持多种语言；在账户菜单中切换显示语言。

---

## 10. 图片：设置与压缩

### 10.1. 图片设置（配图）

**图片设置**页规定文章生成和插入图片的方式：风格、比例、用于 SEO 的替代文字（alt）。

### 10.2. 图片压缩

**图片压缩**页帮你减小图片体积，并把格式转换为 **WebP/AVIF**（对 SEO 友好，加载更快）。

1. 上传图片。
2. 选择格式和压缩级别。
3. 下载优化后的图片。软件直接处理，不会保存你的图片。

---

## 11. 发布文章

### 11.1. 发布到 CMS（WordPress、Wix、Shopify、Haravan、Sapo）

1. 进入**发布**（或打开文章后选择发布）。
2. 选择目标网站**连接**。
3. 检查标题、路径（slug）、描述、封面图。
4. 点击**发布**。如果是之前已发布的文章，软件会**更新**对应的原文章。

### 11.2. 发布到 Google Sheet

除了 CMS，你还可以把文章推送到某个 **Google Sheet**（例如让其他团队继续处理）。一次性连接 Google，选择目标表格，软件会把每篇文章按行写入，并按 slug 更新。

### 11.3. 发布日历

**日历**页允许你安排发布计划：为每篇文章选择日期时间，让内容稳定发出，而不是一次性堆积发布。

---

## 12. 检查与审核

- **审核**：扫描某个页面/文章，评估 SEO 健康度并指出需要修改的错误。
- **落地页检测（Landing Audit）**：单独检查销售/落地页，评估标题、行动号召、说服力结构。

用这些功能来复查已有内容（包括不是本软件创建的文章）。

---

## 13. 报表与引用

- **报表**：查看已用 token 量、AI 费用（按你的货币换算）、按提供商/模型及按成员的统计。用于控制费用。
- **引用（Citations）**：推荐可在文章中引用的权威来源，帮助提升可信度和被 AI 引用的可能性（GEO）。

## 14. 任务与协作

如果组织有多人，使用**我的任务**页进行团队协作：

- **分派文章**：负责人/管理者把文章分派给成员撰写。
- **审批文章**：文章必须先由有权限的人**审批**才能发布。等待你审批的文章会出现在**我的任务**中。
- **评论**：直接在每篇文章上交流。

权限分配（谁可以撰写、发布、审批、管理连接……）在**组织**页设置（见第 17 部分）。

## 18. 常见问题（FAQ）

**我一定要有 AI 的 API 密钥吗？**
是的。撰写和评分功能都使用 AI，所以在连接页中至少需要一个有效的 API 密钥。

**为什么还发布不了文章？**
检查：是否已添加网站连接、连接信息是否仍然正确（点击测试连接），以及账户是否有**发布**权限。

**修改已发布的文章后再次发布，会产生重复文章吗？**
不会。只要你通过同一个连接发布，软件会正确更新原文章。

**SEO/GEO 分数低，去哪里修改？**
进入**优化**页：每个未达标的标准都有具体建议，供你修改后重新评分。

**AI 费用怎么计算？**
按你所用提供商的输入/输出 token 计算。详情见**报表**。

**我想让多人一起协作？**
把他们邀请进**组织**并分配权限。使用**我的任务**中的分派文章 - 审批文章流程。

**在哪里切换界面语言？**
在账户菜单/选择语言处。文章内容的翻译单独在**翻译**页进行。

## 19. 社媒与电商报告（Facebook、Instagram、Threads、TikTok、YouTube、FB 群组、Shopee、TikTok Shop、Lazada）

用真实数据 + AI 分两个阶段分析社媒渠道（自己的或竞品的）：

1. 进入**连接管理** → 为社媒报告添加**数据采集**密钥（按其中说明操作）。每次采集按结果数消耗额度（通常几美分）。你可以添加**多个 Apify 密钥** - 保存前会测试密钥，每次采集随机选用一个密钥（失效或超额的密钥会自动切换到其他密钥）。
2. 打开**社媒报告** → **创建报告** → 弹窗**选择渠道**：Facebook 主页、TikTok、YouTube 或**综合**（多平台）。综合有 2 种方式：输入**关键词/主题**（系统自动在各平台查找热门内容）或直接输入**渠道链接**。
3. **第 1 阶段 - 采集原始数据**：按步骤运行并显示进度（渠道信息 → 帖子/视频 → Facebook 的 Reels/广告 → 评论），然后停在**已采集** - 立即查看各渠道原始数据和指标。
4. **第 2 阶段 - AI 分析**：点击**分析** → 选择 AI 和模型（或"自动"）→ AI 分析品牌、战术、总结；综合报告另有**渠道对比**和分配建议。用其他 AI **重新分析**不产生额外采集费用。
5. 报告列表可按渠道筛选；在系统中查看、**导出 PDF**、**下载 .doc** 或**保存到 Google Drive**（logo + 来源取自系统信息）。

6. **品牌风格**：在报告页点击**品牌风格** → AI 从帖子/视频中提取风格档案（语气、称呼、用词、句式、论证、公式、独特特征、标志性语句、应做/避免）→ 分节查看并**复制/下载 Markdown** 或**复制可复用提示词**，让其他 AI 按此品牌语气写作。

7. **Facebook 群组报告**：在创建弹窗中选择 **Facebook 群组**，粘贴**公开**群组链接（facebook.com/groups/...）。系统收集**帖子及每个帖子的评论**（评论跟随帖子一起分析）、群组信息（成员数、简介）和指标（发帖频率、帖子类型、活跃发帖成员）。AI 从社群视角分析：**热门话题**、**成员洞察**（需求、痛点、问题、用语）以及**内容/渗透机会**和发帖创意。可选择帖子范围：**热门**（近 6 个月互动最高）或**最新**。私密群组无法分析。

8. **Instagram / Threads / Shopee 商品**：在创建弹窗中选择对应渠道。Instagram 输入主页链接或 @username（帖子 + Reels 含**字幕** + 评论）；Threads 输入 @username（帖子 + 回复、转发/引用指标）；Shopee 粘贴**商品链接**（...-i.SHOPID.ITEMID）——系统收集商品信息 + 买家评价（含分项星级、购买规格、卖家回复），AI 分析**商品页**、**买家洞察**（好评/差评、需求、用语）及**改进建议 + 销售内容 + FAQ**。Instagram 和 Threads 也可加入综合报告。

9. **Shopee 店铺**：选择 **Shopee 店铺**，粘贴店铺链接（如 shopee.vn/shopname）或用户名。系统收集**店铺信息**（星级、粉丝、商品总数、回复率）+ **商品目录**（价格、折扣、评分）+ **热销商品评价**（每条评价关联对应商品），AI 分析**目录与价格策略**、**跨商品客户洞察**及**总结与建议**（机会、改进、销售内容）。可像商品报告一样自定义报告名称。

10. **TikTok Shop**：**TikTok Shop** 卡片（及 **Shopee** 卡片）合并两种类型 - 点击后会询问为**商品**还是**整个店铺**创建报告。商品：粘贴商品链接（或 vt.tiktok.com 分享链接/商品 ID）→ 收集价格、折扣、**销量**、库存、规格 + 顾客评价 → AI 分析商品页、买家洞察并建议**带货视频**。店铺：输入与 TikTok Shop 上一致的**店铺名称**（TikTok 无公开店铺链接）→ 系统查找店铺热门商品 + 总销量/预估销售额 + 热门商品评价（关联各商品）→ AI 分析目录与价格、客户洞察及总结。请选对**区域**（默认 VN）。

11. **Lazada**：**Lazada** 卡片同样合并两种类型。商品：粘贴路径中含商品名的完整链接（或 s.lazada.vn 分享链接）→ 一次运行收集价格、折扣、**销量**、卖家 + 顾客评价 → AI 分析商品页、买家洞察与总结。店铺：粘贴店铺链接（lazada.vn/shop/shopname）→ 收集目录 + 按商品关联的评价 → AI 分析目录与价格、客户与总结。

12. **电商总览**（市场调研）：**总览** 卡片现在会询问选择 **社交**（原流程）还是 **电商**。电商模式：输入**商品/细分市场关键词** + 区域 → 系统收集 Shopee、TikTok Shop 和 Lazada 的**热销**商品 → AI 分析**市场图景**（需求、各平台价格）、**跨平台主要对手**及**总结 + 进入计划**（优先平台、建议定价、差异化）。适合开店前的市场/对手调研。

13. **可视化图表**：每份报告都以**图表**部分开头 - 社交渠道：按发布时间的表现、最佳帖子、格式、星期分布（FB 群组另有活跃成员）；商品：星级分布、热门规格；店铺：热销榜、价格分布、星级分布（TikTok Shop 另有 **7 vs 30 天销售节奏**，涨绿跌红）；总览：渠道/平台对比图表。导出 PDF/.doc/Drive 时图表保持不变。

14. **即将推出**：**Zalo** 和 **Messenger** 渠道正在开发中 - 在渠道选择列表中显示"Coming soon"标签，暂不可点击。就绪后将开放。

# คู่มือการใช้งาน

เอกสารนี้จะแนะนำคุณใช้งานซอฟต์แวร์ตั้งแต่ต้นจนจบ: ตั้งแต่ตอนสร้างบัญชีใหม่ เขียนบทความให้ได้มาตรฐาน SEO/GEO ไปจนถึงการเผยแพร่บทความขึ้นเว็บไซต์ แม้คุณยังไม่มีความรู้ด้านเทคนิคเลยก็ทำตามได้

> เคล็ดลับ: ใช้ช่อง "ค้นหาในคู่มือ" ที่ด้านบนของหน้าเพื่อกระโดดไปยังส่วนที่คุณต้องการได้อย่างรวดเร็ว

> ระหว่างใช้งาน ตรงไหนที่มีไอคอน (i) ให้คลิกเพื่ออ่านคำอธิบายโดยละเอียดของช่องนั้น

---

## 1. เริ่มต้นอย่างรวดเร็ว (3 ขั้นตอน)

เพียง 3 ขั้นตอนคุณก็จะมีบทความแรกของคุณ:

1. **ใส่คีย์ API ของ AI** - ซอฟต์แวร์ใช้ AI (Claude, OpenAI, Gemini, DeepSeek) ในการเขียนและให้คะแนน คุณต้องวางคีย์ API ของผู้ให้บริการรายใดรายหนึ่งลงในเมนู **การเชื่อมต่อ** (ดูส่วนที่ 3)
2. **เชื่อมต่อเว็บไซต์** (ยังไม่จำเป็นในตอนนี้) - หากต้องการเผยแพร่บทความขึ้น WordPress, Wix, Shopify, Haravan, Sapo หรือ Google Sheet โดยตรง ให้เพิ่มการเชื่อมต่อในเมนู **การเชื่อมต่อ**
3. **เขียนบทความแรก** - เข้าไปที่ **ตัวแก้ไข** ใส่หัวข้อ ให้ AI สร้างฉบับร่าง แล้วปรับแก้และให้คะแนน

ที่หน้า **ภาพรวม** จะมีรายการตรวจสอบ (checklist) เตรียมไว้เพื่อเตือนให้คุณทำขั้นตอนที่ 1 และ 2 ให้เสร็จ เมื่อทำเสร็จแล้ว checklist จะซ่อนไปเอง

---

## 2. แนวคิดพื้นฐาน

- **องค์กร (Biz)**: พื้นที่ทำงานของคุณ ทุกบทความ การเชื่อมต่อ และพนักงานล้วนอยู่ในองค์กรหนึ่ง คุณสามารถสร้างองค์กรได้หลายแห่งและสลับไปมาได้ด้วยช่องเลือกชื่อองค์กรที่ด้านบนของแถบเมนูด้านซ้าย
- **บทความ (Article)**: เนื้อหาชิ้นหนึ่งที่คุณเรียบเรียง บทความมีสถานะ **ฉบับร่าง** (draft) หรือ **เผยแพร่แล้ว** (published)
- **คะแนน SEO / AEO / GEO**: ตัววัดคุณภาพบทความสามอย่าง:
  - **SEO**: ระดับการปรับให้เหมาะสมสำหรับเครื่องมือค้นหา (Google) - หัวเรื่อง คำอธิบาย แท็ก heading คีย์เวิร์ด และลิงก์
  - **AEO**: ระดับการปรับให้เหมาะสมเพื่อให้ติดกล่องคำตอบ (Answer Engine) เช่น Google AI Overviews
  - **GEO**: ระดับการปรับให้เหมาะสมเพื่อให้ AI (ChatGPT, Perplexity, Gemini) อ้างอิงบทความของคุณ
- **Token**: หน่วยวัดปริมาณตัวอักษรที่ AI ประมวลผล "Token เข้า" คือข้อมูลที่คุณส่งให้ AI ส่วน "Token ออก" คือเนื้อหาที่ AI สร้าง ค่าใช้จ่ายของ AI คิดตาม token; ดูรายละเอียดที่ **รายงาน**
- **การเชื่อมต่อ (Connection)**: การเชื่อมโยงไปยังเว็บไซต์/ช่องทางเพื่อเผยแพร่บทความ (WordPress, Wix, Shopify, Haravan, Sapo, Google Sheet)

---

## 3. การเชื่อมต่อ: คีย์ API ของ AI และเว็บไซต์

นี่คือที่ที่คุณตั้งค่าทุกอย่างเพื่อให้ซอฟต์แวร์ทำงานได้ เปิดเมนู **การเชื่อมต่อ** ที่แถบเมนูด้านซ้าย (กลุ่ม **ระบบ**)

### 3.1. เพิ่มคีย์ API ของ AI

ซอฟต์แวร์ไม่ได้มี AI มาให้ในตัว - คุณใช้คีย์ API ของคุณเอง จึงควบคุมค่าใช้จ่ายและโควตาได้เอง

1. เข้าไปที่ **การเชื่อมต่อ** → ส่วน **คีย์ API ของ AI**
2. เลือกผู้ให้บริการ: **Claude (Anthropic)**, **OpenAI**, **Gemini (Google)** หรือ **DeepSeek**
3. วางคีย์ API (นำมาจากหน้าจัดการของผู้ให้บริการรายนั้น) แล้ว **บันทึก**
4. เปิดสวิตช์เพื่อเปิดใช้งาน คุณสามารถเพิ่มผู้ให้บริการได้หลายราย และเลือกรายที่ใช้เป็นหลัก

> เคล็ดลับ: หากยังไม่มีคีย์ ให้สมัครบัญชีกับผู้ให้บริการ AI สร้าง API key แล้วกลับมาวาง คีย์จะถูกจัดเก็บอย่างปลอดภัย และจะไม่แสดงแบบเต็มอีกครั้งหลังจากบันทึกแล้ว

### 3.2. เชื่อมต่อเว็บไซต์เพื่อเผยแพร่บทความ

1. เข้าไปที่ **การเชื่อมต่อ** → ส่วน **เชื่อมต่อเว็บไซต์** → **เพิ่มการเชื่อมต่อ**
2. เลือกแพลตฟอร์ม: **WordPress, Wix, Shopify, Haravan, Sapo**
3. ทำตามคำแนะนำที่แสดงในหน้าต่างสำหรับแต่ละแพลตฟอร์ม (ใส่ที่อยู่เว็บไซต์ บัญชี/รหัสผ่านแอปพลิเคชัน หรือ token)
4. กด **ทดสอบการเชื่อมต่อ** เพื่อให้แน่ใจว่าข้อมูลถูกต้อง แล้ว **บันทึก**

หลังจากเชื่อมต่อแล้ว คุณสามารถเผยแพร่หรืออัปเดตบทความได้โดยตรงจากซอฟต์แวร์ (ดูส่วนที่ 11)

---

## 4. การวิจัยคีย์เวิร์ด

เมนู **คีย์เวิร์ด** ช่วยให้คุณค้นหาและจัดกลุ่มคีย์เวิร์ดก่อนเขียน เพื่อให้บทความตรงกับความต้องการของผู้ค้นหา

1. เข้าไปที่ **คีย์เวิร์ด** ใส่คีย์เวิร์ดต้นทางหนึ่งคำ (ตัวอย่าง: "รองเท้าวิ่ง")
2. ซอฟต์แวร์จะแนะนำชุดคีย์เวิร์ดที่เกี่ยวข้องพร้อมความตั้งใจในการค้นหาและคำถามที่พบบ่อย (แบบ GEO)
3. เลือกคีย์เวิร์ดที่เหมาะสมและบันทึกเป็นชุดคีย์เวิร์ดเพื่อใช้ในขั้นตอนการวางแผน

> เคล็ดลับ: สังเกตคอลัมน์ความตั้งใจ (intent) คีย์เวิร์ด "ซื้อ/ราคา" เหมาะกับบทความขายสินค้า; คีย์เวิร์ด "วิธี/คืออะไร" เหมาะกับบทความแนะนำ

---

## 5. การวางแผนเนื้อหา

เมนู **แผน** เปลี่ยนชุดคีย์เวิร์ดให้เป็นรายการบทความที่ต้องเขียน พร้อมหัวเรื่องและโครงร่างที่แนะนำ

1. เข้าไปที่ **แผน** เลือกชุดคีย์เวิร์ดหรือใส่หัวข้อ
2. ซอฟต์แวร์จะเสนอหัวเรื่องบทความ (title) และโครงร่าง (outline)
3. ตรวจดู แก้ไข แล้วส่งแต่ละรายการไปยัง **ตัวแก้ไข** เพื่อเขียน

วิธีนี้ช่วยให้คุณสร้างคลัสเตอร์เนื้อหา (topic cluster) อย่างเป็นระบบ แทนที่จะเขียนแบบกระจัดกระจาย

---

## 6. ตัวแก้ไข (เขียนบทความ)

เมนู **ตัวแก้ไข** คือที่ที่คุณเขียนและทำบทความให้สมบูรณ์

1. ใส่ **หัวเรื่อง** และ **คีย์เวิร์ดเป้าหมาย**
2. กดเพื่อให้ AI สร้าง **ฉบับร่าง** ตามหัวข้อ คุณยังสามารถเขียนเองหรือวางเนื้อหาที่มีอยู่แล้วได้
3. ใช้เครื่องมือช่วยเหลือ:
   - **เขียนใหม่ / ขยายความ / ย่อ** ย่อหน้า
   - **ทำให้เป็นธรรมชาติ (humanize)**: ทำให้ถ้อยคำเป็นธรรมชาติ ลดสำเนียงหุ่นยนต์
   - **ตรวจสอบข้อเท็จจริง (fact-check)**: ตรวจสอบข้อมูลที่อาจผิดพลาดได้ง่าย
   - **แทรกภาพประกอบ**: สร้างภาพหรือแนะนำภาพ (ดูส่วนที่ 10)
4. ดูคะแนน **SEO / AEO / GEO** ที่อัปเดตทันที และทำตามคำแนะนำเพื่อเพิ่มคะแนน
5. กด **บันทึก** - บทความจะเข้าไปอยู่ในรายการ **บทความ** ในสถานะฉบับร่าง

> เคล็ดลับ: เขียนหัวเรื่องให้มีคีย์เวิร์ดหลัก แบ่งบทความด้วย heading ที่ชัดเจน และตอบคำถามตรงไปตรงมาตั้งแต่ย่อหน้าแรก - ทั้งสามอย่างนี้ดีทั้งต่อ SEO และ GEO

---

## 7. การจัดการบทความ

เมนู **บทความ** แสดงรายการบทความทั้งหมดในองค์กร

- กรองตาม **สถานะ** (ฉบับร่าง / เผยแพร่แล้ว) และ **ภาษา**
- เปิดบทความหนึ่งเพื่อ **แก้ไขต่อ**, **ให้คะแนนใหม่**, **แปล**, **ปรับให้เหมาะสม** หรือ **เผยแพร่**
- คอลัมน์คะแนนช่วยให้คุณเห็นได้อย่างรวดเร็วว่าบทความใดต้องปรับปรุง

> หมายเหตุ: เมื่อคุณแก้ไขบทความที่เผยแพร่แล้วและเผยแพร่ซ้ำ ซอฟต์แวร์จะ **อัปเดตบทความเดิมบนเว็บไซต์อย่างถูกต้อง** (ไม่สร้างบทความซ้ำ) ตราบเท่าที่คุณเผยแพร่ผ่านการเชื่อมต่อเดียวกัน

---

## 8. การปรับ SEO และ GEO ให้เหมาะสม

เมนู **ปรับให้เหมาะสม** ให้คะแนนอย่างละเอียดและชี้จุดที่ต้องแก้ไขได้อย่างแม่นยำ

1. เลือกบทความที่ต้องการปรับให้เหมาะสม
2. ดูตารางคะแนนตามแต่ละเกณฑ์: หัวเรื่อง คำอธิบาย (meta) โครงสร้าง heading ความหนาแน่นของคีย์เวิร์ด ลิงก์ภายใน ข้อมูลที่มีโครงสร้าง (schema) ความสามารถในการถูก AI อ้างอิง...
3. แต่ละรายการที่ "ยังไม่ผ่าน" จะมีคำแนะนำที่เจาะจง นำคำแนะนำไปใช้แล้วให้คะแนนใหม่จนกว่าคะแนนจะสูง

**เกี่ยวกับลิงก์ภายใน**: ควรลิงก์ไปยังบทความที่ **เผยแพร่จริงแล้ว** เท่านั้น (มีเส้นทางจริง) อย่าใส่ลิงก์ไปยังหน้าที่ยังไม่มีอยู่

**เกี่ยวกับลิงก์ออกภายนอก**: ทุกเส้นทางที่ออกไปยังเว็บไซต์อื่นควรเปิดในแท็บใหม่ เพื่อไม่ให้ผู้อ่านออกจากหน้าของคุณ

---

## 9. การแปลและหลายภาษา

เมนู **การแปล** ช่วยสร้างบทความในภาษาอื่น

1. เลือกบทความต้นฉบับและภาษาปลายทาง (หนึ่งหรือหลายภาษา)
2. ซอฟต์แวร์ไม่ได้แปลแบบตรงตัว แต่ **ปรับให้เข้ากับท้องถิ่น**: ปรับตัวอย่าง หน่วย สำนวน แล้วปรับ SEO/GEO ให้เหมาะสมใหม่ตามคีย์เวิร์ดท้องถิ่น
3. ตรวจทานบทแปลอีกครั้ง แก้ไขหากจำเป็น แล้วบันทึกเป็นบทความแยกต่างหาก

หน้าจอของซอฟต์แวร์รองรับหลายภาษา; เปลี่ยนภาษาที่แสดงได้ที่เมนูบัญชี

---

## 10. รูปภาพ: การตั้งค่าและการบีบอัด

### 10.1. ตั้งค่ารูปภาพ (ภาพประกอบ)

เมนู **ตั้งค่ารูปภาพ** กำหนดวิธีสร้างและแทรกภาพสำหรับบทความ: สไตล์ สัดส่วน และข้อความแทน (alt) สำหรับ SEO

### 10.2. บีบอัดรูปภาพ

เมนู **บีบอัดรูปภาพ** ช่วยลดขนาดไฟล์ภาพและเปลี่ยนรูปแบบเป็น **WebP/AVIF** (เป็นมิตรกับ SEO โหลดเร็วขึ้น)

1. อัปโหลดรูปภาพ
2. เลือกรูปแบบและระดับการบีบอัด
3. ดาวน์โหลดภาพที่ปรับให้เหมาะสมแล้ว ซอฟต์แวร์ประมวลผลโดยตรง ไม่จัดเก็บรูปภาพของคุณไว้

---

## 11. การเผยแพร่บทความ

### 11.1. เผยแพร่ขึ้น CMS (WordPress, Wix, Shopify, Haravan, Sapo)

1. เข้าไปที่ **เผยแพร่** (หรือเปิดบทความแล้วเลือกเผยแพร่)
2. เลือก **การเชื่อมต่อ** เว็บไซต์ปลายทาง
3. ตรวจสอบหัวเรื่อง เส้นทาง (slug) คำอธิบาย และภาพปก
4. กด **เผยแพร่** หากเป็นบทความที่เผยแพร่ไปก่อนหน้านี้แล้ว ซอฟต์แวร์จะ **อัปเดต** บทความเดิมอย่างถูกต้อง

### 11.2. เผยแพร่ลง Google Sheet

นอกจาก CMS แล้ว คุณยังสามารถส่งบทความเข้า **Google Sheet** ได้ (เช่น เพื่อให้ทีมอื่นดำเนินการต่อ) เชื่อมต่อ Google ครั้งเดียว เลือกสเปรดชีตปลายทาง ซอฟต์แวร์จะบันทึกแต่ละบทความลงแต่ละแถวและอัปเดตตาม slug

### 11.3. ปฏิทินเผยแพร่บทความ

เมนู **ปฏิทิน** ช่วยให้จัดตารางเผยแพร่ได้: เลือกวันเวลาสำหรับแต่ละบทความเพื่อให้เนื้อหาออกอย่างสม่ำเสมอ แทนที่จะเผยแพร่พร้อมกันทีเดียว

---

## 12. การตรวจสอบและ audit

- **ตรวจสอบ**: สแกนหน้า/บทความเพื่อประเมินสุขภาพ SEO และชี้ข้อผิดพลาดที่ต้องแก้ไข
- **ตรวจสอบแลนดิ้ง (Landing Audit)**: ตรวจสอบเฉพาะหน้าขายสินค้า/หน้าปลายทาง ประเมินหัวเรื่อง คำเชิญชวนให้ลงมือทำ และโครงสร้างการโน้มน้าว

ใช้เมนูเหล่านี้เพื่อทบทวนเนื้อหาที่มีอยู่แล้ว (รวมถึงบทความที่ไม่ได้สร้างจากซอฟต์แวร์)

---

## 13. รายงานและการอ้างอิง

- **รายงาน**: ดูปริมาณ token ที่ใช้ ค่าใช้จ่าย AI (แปลงเป็นสกุลเงินของคุณ) สถิติตามผู้ให้บริการ/โมเดล และตามพนักงาน ใช้เพื่อควบคุมค่าใช้จ่าย
- **การอ้างอิง (Citations)**: แนะนำแหล่งข้อมูลที่น่าเชื่อถือเพื่อใช้อ้างอิงในบทความ ช่วยเพิ่มความน่าเชื่อถือและความสามารถในการถูก AI อ้างอิง (GEO)

## 14. งานและการทำงานร่วมกัน

หากองค์กรมีคนหลายคน ให้ใช้เมนู **งานของฉัน** เพื่อทำงานเป็นทีม:

- **มอบหมายบทความ**: เจ้าของ/ผู้จัดการมอบหมายบทความให้พนักงานเขียน
- **อนุมัติบทความ**: บทความต้องได้รับการ **อนุมัติ** จากผู้มีสิทธิ์ก่อนเผยแพร่ บทความที่รอคุณอนุมัติจะแสดงใน **งานของฉัน**
- **ความคิดเห็น**: พูดคุยกันได้ทันทีบนแต่ละบทความ

การกำหนดสิทธิ์ (ใครเขียนได้ เผยแพร่ได้ อนุมัติได้ จัดการการเชื่อมต่อได้...) ตั้งค่าที่หน้า **องค์กร** (ดูส่วนที่ 17)

## 15. ข่าวสารและการแจ้งเตือน

- **กระดิ่งแจ้งเตือน** (มุมบน): การอัปเดตและการแจ้งเตือนสำหรับคุณ
- **ข่าวสาร**: ข่าวและเคล็ดลับการใช้ซอฟต์แวร์ ข่าว **ใหม่** จะมีป้าย "ใหม่"; เมื่อคุณเปิดอ่านข่าวใดข่าวหนึ่ง ป้ายของข่าวนั้นจะหายไป มีปุ่ม **ทำเครื่องหมายว่าอ่านแล้วทั้งหมด** เพื่อล้างได้อย่างรวดเร็ว

## 16. แพ็กเกจและโควตา

เมนู **แพ็กเกจ** บอกให้คุณรู้ว่าคุณอยู่ในแพ็กเกจใด เหลือสิทธิ์เขียนบทความในรอบนี้อีกเท่าไร และวันที่ต่ออายุ

- ดูโควตาที่เหลือและประวัติ
- อัปเกรดแพ็กเกจเมื่อต้องการโควตาหรือฟีเจอร์เพิ่ม
- หากบัญชีได้รับสิทธิ์เพิ่ม (overage) หรือไม่จำกัด ข้อมูลก็จะแสดงที่นี่ด้วย

## 17. บัญชี ความปลอดภัย และองค์กร

### 17.1. บัญชี

เมนู **บัญชี** (กดที่ชื่อของคุณที่ด้านล่างของเมนู) ช่วยให้เปลี่ยนชื่อที่แสดงและ **เปลี่ยนรหัสผ่าน** ได้ หากลืมรหัสผ่าน ให้ใช้ลิงก์ "ลืมรหัสผ่าน" ที่หน้าเข้าสู่ระบบเพื่อตั้งใหม่ผ่านอีเมล

### 17.2. องค์กร (Biz)

กดที่ชื่อองค์กรที่ด้านบนของเมนู → **จัดการองค์กร**:

- **พนักงาน**: เชิญคนเข้าองค์กรและกำหนดสิทธิ์ตามบทบาท
- **เสียงของแบรนด์ (Brand voice)**: กำหนดสำนวนเพื่อให้ AI เขียนได้ตรงกับเอกลักษณ์ของแบรนด์
- **Token API ขององค์กร**: สร้างคีย์เพื่อให้ระบบอื่นเรียกใช้ API ของคุณ (สำหรับนักพัฒนา)
- **สลับ/สร้างองค์กรใหม่**: จัดการพื้นที่ทำงานหลายแห่ง

## 18. คำถามที่พบบ่อย (FAQ)

**ฉันจำเป็นต้องมีคีย์ API ของ AI หรือไม่?**
จำเป็น ฟีเจอร์เขียนและให้คะแนนใช้ AI จึงต้องมีคีย์ API ที่ยังใช้งานได้อย่างน้อยหนึ่งคีย์ในเมนูการเชื่อมต่อ

**ทำไมยังเผยแพร่บทความไม่ได้?**
ตรวจสอบว่า: เพิ่มการเชื่อมต่อเว็บไซต์แล้วหรือยัง ข้อมูลการเชื่อมต่อยังถูกต้องอยู่หรือไม่ (กดทดสอบการเชื่อมต่อ) และบัญชีมีสิทธิ์ **เผยแพร่** หรือไม่

**แก้ไขบทความที่เผยแพร่แล้วและเผยแพร่ซ้ำจะสร้างบทความซ้ำหรือไม่?**
ไม่ ซอฟต์แวร์อัปเดตบทความเดิมอย่างถูกต้องหากคุณเผยแพร่ผ่านการเชื่อมต่อเดียวกัน

**ถ้าคะแนน SEO/GEO ต่ำ จะแก้ไขที่ไหน?**
เข้าไปที่เมนู **ปรับให้เหมาะสม**: แต่ละเกณฑ์ที่ยังไม่ผ่านจะมีคำแนะนำเจาะจงให้คุณแก้ไขแล้วให้คะแนนใหม่

**ค่าใช้จ่าย AI คิดอย่างไร?**
คิดตาม token เข้า/ออกของผู้ให้บริการที่คุณใช้ ดูรายละเอียดที่ **รายงาน**

**ฉันต้องการให้หลายคนทำงานร่วมกัน?**
เชิญพวกเขาเข้า **องค์กร** และกำหนดสิทธิ์ ใช้ขั้นตอนมอบหมายบทความ - อนุมัติบทความใน **งานของฉัน**

**เปลี่ยนภาษาของหน้าจอได้ที่ไหน?**
ที่เมนูบัญชี/เลือกภาษา ส่วนเนื้อหาบทความจะแปลแยกต่างหากที่เมนู **การแปล**

## 19. รายงานโซเชียลและอีคอมเมิร์ซ (Facebook, Instagram, Threads, TikTok, YouTube, กลุ่ม FB, Shopee, TikTok Shop, Lazada)

วิเคราะห์ช่องโซเชียล (ของคุณหรือคู่แข่ง) ด้วยข้อมูลจริง + AI ใน 2 เฟส:

1. ไปที่ **การจัดการการเชื่อมต่อ** → เพิ่มคีย์ **การเก็บข้อมูล** สำหรับรายงานโซเชียล (ทำตามคำแนะนำที่นั่น) การเก็บแต่ละครั้งใช้เครดิตตามผลลัพธ์ (มักไม่กี่เซนต์) คุณเพิ่ม**คีย์ Apify ได้หลายคีย์** - ระบบทดสอบคีย์ก่อนบันทึก และการเก็บแต่ละครั้งจะสุ่มใช้คีย์หนึ่ง (คีย์ที่ใช้ไม่ได้หรือเกินโควตาจะสลับไปคีย์อื่นอัตโนมัติ)
2. เปิด **รายงานโซเชียล** → **สร้างรายงาน** → ป๊อปอัปให้**เลือกช่องทาง**: เพจ Facebook, TikTok, YouTube หรือ**ภาพรวม** (หลายแพลตฟอร์ม) ภาพรวมมี 2 แบบ: ใส่**คีย์เวิร์ด/หัวข้อ** (ระบบค้นหาคอนเทนต์เด่นแต่ละแพลตฟอร์มอัตโนมัติ) หรือใส่**ลิงก์ช่อง**โดยตรง
3. **เฟส 1 - เก็บข้อมูลดิบ**: ทำทีละขั้นพร้อมความคืบหน้า (ข้อมูลช่อง → โพสต์/วิดีโอ → Reels/โฆษณาสำหรับ Facebook → คอมเมนต์) แล้วหยุดที่ **เก็บข้อมูลแล้ว** - ดูข้อมูลดิบ + ตัวชี้วัดรายช่องได้ทันที
4. **เฟส 2 - วิเคราะห์ด้วย AI**: กด **วิเคราะห์** → เลือก AI และโมเดล (หรือ "อัตโนมัติ") → AI วิเคราะห์แบรนด์ กลยุทธ์ สรุป; รายงานภาพรวมมี**การเปรียบเทียบระหว่างช่อง**และข้อเสนอการจัดสรรเพิ่ม **วิเคราะห์ใหม่**ด้วย AI อื่นไม่มีค่าเก็บข้อมูลเพิ่ม
5. รายการรายงานกรองตามช่องได้; ดูในระบบ, **ส่งออก PDF**, **ดาวน์โหลด .doc** หรือ **บันทึกไปยัง Google Drive** (โลโก้ + แหล่งที่มาจากข้อมูลระบบ)

6. **สไตล์แบรนด์**: ในหน้ารายงาน กด **สไตล์แบรนด์** → AI สกัดโปรไฟล์สไตล์จากโพสต์/วิดีโอ (น้ำเสียง วิธีเรียก คำศัพท์ โครงสร้างประโยค การให้เหตุผล สูตร เอกลักษณ์ วลีประจำตัว ควรทำ/ควรเลี่ยง) → ดูตามหัวข้อ แล้ว**คัดลอก/ดาวน์โหลด Markdown** หรือ**คัดลอกพรอมป์ตใช้ซ้ำ**ให้ AI อื่นเขียนด้วยน้ำเสียงแบรนด์นี้ได้

7. **รายงานกลุ่ม Facebook**: เลือก **กลุ่ม Facebook** ในป๊อปอัปสร้างรายงาน แล้ววางลิงก์กลุ่ม**สาธารณะ** (facebook.com/groups/...) ระบบจะเก็บ**โพสต์พร้อมคอมเมนต์ของแต่ละโพสต์** (คอมเมนต์ผูกกับโพสต์เพื่อวิเคราะห์ร่วมกัน) ข้อมูลกลุ่ม (จำนวนสมาชิก คำอธิบาย) และตัวชี้วัด (ความถี่ รูปแบบโพสต์ สมาชิกที่โพสต์เด่น) AI วิเคราะห์ในมุมคอมมูนิตี้: **หัวข้อร้อนแรง** **อินไซต์สมาชิก** (ความต้องการ ปัญหา คำถาม ภาษา) และ**โอกาสคอนเทนต์/seeding** พร้อมไอเดียโพสต์ เลือกขอบเขตโพสต์: **ยอดนิยม** (6 เดือนล่าสุด) หรือ **ล่าสุด** กลุ่มส่วนตัววิเคราะห์ไม่ได้

8. **Instagram / Threads / สินค้า Shopee**: เลือกช่องทางในป๊อปอัปสร้างรายงาน Instagram ใส่ลิงก์โปรไฟล์หรือ @username (โพสต์ + Reels พร้อม**คำบรรยาย** + คอมเมนต์); Threads ใส่ @username (โพสต์ + ตอบกลับ ตัวชี้วัดรีโพสต์/อ้างอิง); Shopee วาง**ลิงก์สินค้า** (...-i.SHOPID.ITEMID) - ระบบเก็บข้อมูลสินค้า + รีวิวผู้ซื้อ (พร้อมดาวรายด้าน ตัวเลือกที่ซื้อ การตอบของร้าน) แล้ว AI วิเคราะห์**หน้าสินค้า** **อินไซต์ผู้ซื้อ** (ชม/ตำหนิ ความต้องการ ภาษา) และ**ข้อเสนอปรับปรุง + คอนเทนต์ขาย + FAQ** Instagram และ Threads เข้าร่วมรายงานภาพรวมได้ด้วย

9. **ร้านค้า Shopee**: เลือก **ร้านค้า Shopee** วางลิงก์ร้าน (เช่น shopee.co.th/shopname) หรือ username ระบบจะเก็บ**ข้อมูลร้าน** (ดาว ผู้ติดตาม สินค้าทั้งหมด อัตราตอบกลับ) + **แคตตาล็อกสินค้า** (ราคา ส่วนลด คะแนน) + **รีวิวสินค้าขายดี** (รีวิวผูกกับสินค้าแต่ละชิ้น) แล้ว AI วิเคราะห์**แคตตาล็อกและกลยุทธ์ราคา** **อินไซต์ลูกค้าข้ามสินค้า** และ**สรุปพร้อมข้อเสนอ** (โอกาส การปรับปรุง คอนเทนต์ขาย) ตั้งชื่อรายงานได้เหมือนรายงานสินค้า

10. **TikTok Shop**: การ์ด **TikTok Shop** (และการ์ด **Shopee**) รวมทั้งสองประเภท - เมื่อคลิกจะถามว่าสร้างรายงานสำหรับ**สินค้า**หรือ**ทั้งร้าน** สินค้า: วางลิงก์สินค้า (หรือลิงก์แชร์ vt.tiktok.com / ID สินค้า) → เก็บราคา ส่วนลด **ยอดขาย** สต็อก ตัวเลือกสินค้า + รีวิวลูกค้า → AI วิเคราะห์หน้าสินค้า อินไซต์ผู้ซื้อ และแนะนำ**วิดีโอขายของ** ร้านค้า: กรอก**ชื่อร้าน**ให้ตรงกับบน TikTok Shop (ไม่มี URL ร้านสาธารณะ) → ระบบหาสินค้าเด่นของร้าน + ยอดขายรวม/รายได้โดยประมาณ + รีวิวสินค้าขายดี (ผูกกับแต่ละสินค้า) → AI วิเคราะห์แคตตาล็อกและราคา อินไซต์ลูกค้า และสรุป อย่าลืมเลือก**ภูมิภาค**ให้ถูกต้อง (ค่าเริ่มต้น VN)

11. **Lazada**: การ์ด **Lazada** รวมทั้งสองประเภทเช่นกัน สินค้า: วางลิงก์เต็มที่มีชื่อสินค้าในพาธ (หรือลิงก์แชร์ s.lazada) → รันครั้งเดียวเก็บราคา ส่วนลด **ยอดขาย** ผู้ขาย + รีวิวลูกค้า → AI วิเคราะห์หน้าสินค้า อินไซต์ผู้ซื้อ และสรุป ร้านค้า: วางลิงก์ร้าน (lazada.co.th/shop/shopname) → เก็บแคตตาล็อก + รีวิวผูกกับแต่ละสินค้า → AI วิเคราะห์แคตตาล็อกและราคา ลูกค้า และสรุป

12. **ภาพรวม E-commerce** (วิจัยตลาด): การ์ด **ภาพรวม** ตอนนี้จะถามว่าเลือก **Social** (โฟลว์เดิม) หรือ **E-commerce** โหมด E-commerce: กรอก**คีย์เวิร์ดสินค้า/นิช** + ภูมิภาค → ระบบเก็บสินค้า**ขายดี**บน Shopee, TikTok Shop และ Lazada → AI วิเคราะห์**ภาพตลาด** (ความต้องการ ราคาแต่ละมาร์เก็ตเพลส) **คู่แข่งเด่นข้ามมาร์เก็ตเพลส** และ**สรุป + แผนเข้าตลาด** (มาร์เก็ตเพลสที่ควรเริ่ม ราคาแนะนำ การสร้างความต่าง) เหมาะสำหรับวิจัยก่อนเริ่มขาย

13. **กราฟภาพ**: ทุกรายงานเริ่มด้วยส่วน**กราฟ** - ช่องทางโซเชียล: ประสิทธิภาพตามเวลาโพสต์ โพสต์เด่น รูปแบบ วันในสัปดาห์ (กลุ่ม FB เพิ่มสมาชิกที่โพสต์บ่อย); สินค้า: การกระจายดาว ตัวเลือกยอดนิยม; ร้านค้า: ขายดี การกระจายราคา ดาว (TikTok Shop เพิ่ม**จังหวะขาย 7 vs 30 วัน** เขียว/แดงตามขึ้น/ลง); ภาพรวม: กราฟเปรียบเทียบช่องทาง/มาร์เก็ตเพลส กราฟคงอยู่เมื่อส่งออก PDF/.doc/Drive

14. **เร็ว ๆ นี้**: ช่องทาง **Zalo** และ **Messenger** กำลังพัฒนา - จะแสดงในรายการเลือกช่องพร้อมป้าย "Coming soon" และยังกดไม่ได้ ระบบจะเปิดใช้เมื่อพร้อม

ข้อจำกัดแพ็กเกจ: จำนวนรายงานโซเชียลต่อเดือนและช่องทางที่ใช้ได้ขึ้นอยู่กับแพ็กเกจของเจ้าของบัญชี แพ็กเกจ Free วิเคราะห์ได้เฉพาะเพจ Facebook ดูขีดจำกัดปัจจุบันได้ที่หน้า**แพ็กเกจ** สำหรับแพ็กเกจ Free รายงานเพจจะแสดงเฉพาะส่วนต้น (ถึงกลุ่มเป้าหมาย) และส่งออกไฟล์ PDF/DOC/Drive ไม่ได้ - อัปเกรดเพื่อปลดล็อกการวิเคราะห์เต็มและการส่งออก

เคล็ดลับ: โพสต์อ้างอิง "โพสต์ 1..N" ตามช่อง (มีชื่อแพลตฟอร์มเมื่อหลายช่อง); ล้มเหลวกลางทางกด **ลองใหม่**

## 20. ต้องการความช่วยเหลือเพิ่มเติม?

- ทบทวนส่วนที่เกี่ยวข้องในคู่มือนี้อีกครั้ง (ใช้ช่องค้นหาที่ด้านบนของหน้า)
- สำหรับบัญชีใหม่ คุณสามารถเปิดส่วน **แนะนำอย่างรวดเร็ว** อีกครั้งได้ด้วยปุ่ม "ดูคู่มืออีกครั้ง" ที่หน้าภาพรวม
- หากยังติดขัด ให้ติดต่อผู้ดูแลระบบของคุณ

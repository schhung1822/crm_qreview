# 利用ガイド

このドキュメントでは、ソフトウェアの使い方をはじめから終わりまでご案内します。アカウントの新規作成から、SEO/GEO に最適化された記事の作成、そしてウェブサイトへの記事公開までをカバーします。技術的な知識がまったくなくても、手順どおりに進めていただけます。

> ヒント: 必要な項目にすばやく移動するには、ページ上部の「ガイド内を検索」ボックスをご利用ください。

> 利用中に (i) アイコンが表示されている箇所は、クリックするとその項目の詳しい説明を読めます。

---

## 1. クイックスタート(3ステップ)

わずか3ステップで最初の記事を作成できます。

1. **AI の API キーを入力する** - 本ソフトウェアは記事の作成や採点に AI(Claude、OpenAI、Gemini、DeepSeek)を利用します。いずれかのプロバイダーの API キーを**連携**の項目に貼り付けてください(第3章を参照)。
2. **ウェブサイトを連携する**(すぐには必須ではありません) - WordPress、Wix、Shopify、Haravan、Sapo、または Google Sheet に記事を直接公開したい場合は、**連携**の項目に連携を追加してください。
3. **最初の記事を書く** - **エディタ**に移動してテーマを入力し、AI に下書きを作成させてから、内容を調整して採点します。

**ダッシュボード**のページには、ステップ1と2の完了を促すチェックリストがあらかじめ用意されています。完了すると、チェックリストは自動的に非表示になります。

---

## 2. 基本的な用語

- **組織(Biz)**: あなたのワークスペースです。すべての記事、連携、メンバーはいずれかの組織に属します。組織は複数作成でき、左側メニュー上部の組織名を選択するボックスで切り替えられます。
- **記事(Article)**: あなたが作成するコンテンツです。記事には**下書き**(draft)または**公開済み**(published)のステータスがあります。
- **SEO / AEO / GEO スコア**: 記事の品質を測る3つの指標です。
  - **SEO**: 検索エンジン(Google)向けの最適化度合いです - タイトル、説明文、見出しタグ、キーワード、リンクなど。
  - **AEO**: Google AI Overviews のような回答エンジン(Answer Engine)に取り上げられるための最適化度合いです。
  - **GEO**: AI(ChatGPT、Perplexity、Gemini)にあなたの記事が引用されるための最適化度合いです。
- **token**: AI が処理する文字量を測る単位です。「入力 token」はあなたが AI に送るデータ、「出力 token」は AI が生成する内容です。AI の費用は token に応じて計算されます。詳細は**レポート**をご覧ください。
- **連携(Connection)**: 記事を公開するためのウェブサイト/チャネルへのリンクです(WordPress、Wix、Shopify、Haravan、Sapo、Google Sheet)。

---

## 3. 連携: AI の API キーとウェブサイト

ここは、ソフトウェアを動作させるためのあらゆる設定を登録する場所です。左側メニュー(**システム**グループ)の**連携**を開いてください。

### 3.1. AI の API キーを追加する

本ソフトウェアには AI が同梱されていません。ご自身の API キーを使うため、費用と利用上限を主体的に管理できます。

1. **連携** → **AI の API キー**エリアに移動します。
2. プロバイダーを選択します: **Claude (Anthropic)**、**OpenAI**、**Gemini (Google)**、または **DeepSeek**。
3. API キー(そのプロバイダーの管理画面から取得したもの)を貼り付けて**保存**します。
4. スイッチをオンにして有効化します。複数のプロバイダーを追加し、メインで使うものを選ぶこともできます。

> ヒント: キーをまだお持ちでない場合は、AI プロバイダーでアカウントを登録し、API キーを作成してから戻って貼り付けてください。キーは安全に保管され、保存後は完全な形では再表示されません。

### 3.2. 記事公開のためにウェブサイトを連携する

1. **連携** → **ウェブサイト連携**エリア → **連携を追加**に移動します。
2. プラットフォームを選択します: **WordPress、Wix、Shopify、Haravan、Sapo**。
3. 各プラットフォームについてウィンドウ内に表示される案内に従います(サイトのアドレス、アカウント/アプリケーションパスワードまたは token を入力します)。
4. **連携をテスト**を押して情報が正しいことを確認してから、**保存**します。

連携後は、ソフトウェアから直接記事を公開または更新できます(第11章を参照)。

## 4. キーワード調査

**キーワード**の項目では、検索者のニーズに合った記事にするために、執筆前にキーワードを見つけてグループ化できます。

1. **キーワード**に移動し、元となるキーワードを入力します(例:「ランニングシューズ」)。
2. ソフトウェアが、検索意図やよくある質問(GEO 形式)を添えて、関連キーワードのセットを提案します。
3. 適したキーワードを選び、キーワードセットとして保存して、計画のステップで使います。

> ヒント: 意図(intent)の列に注目してください。「購入/価格」のキーワードは販売記事に、「方法/とは」のキーワードはハウツー記事に適しています。

---

## 5. コンテンツの計画

**プラン(計画)**の項目では、キーワードセットを、タイトルと推奨アウトライン付きの執筆すべき記事のリストに変換します。

1. **プラン(計画)**に移動し、キーワードセットを選ぶかテーマを入力します。
2. ソフトウェアが記事のタイトルとアウトラインを提案します。
3. 内容を確認・編集してから、各項目を**エディタ**に送って執筆します。

この方法により、ばらばらに書くのではなく、体系的にトピッククラスターを構築できます。

---

## 6. エディタ(記事を書く)

**エディタ**の項目は、記事を書いて仕上げる場所です。

1. **タイトル**と**ターゲットキーワード**を入力します。
2. ボタンを押すと、AI がテーマに沿って**下書き**を作成します。ご自身で書いたり、既存の内容を貼り付けたりすることもできます。
3. 補助ツールを活用します:
   - 段落を**書き直す / 拡張する / 短縮する**。
   - **人間らしく(humanize)**: 文章を自然にし、機械的な口調を和らげます。
   - **ファクトチェック(fact-check)**: 誤りやすい情報を確認します。
   - **挿絵を挿入する**: 画像を生成したり、画像を提案したりします(第10章を参照)。
4. **SEO / AEO / GEO** のスコアがリアルタイムで更新されるのを確認し、提案に従ってスコアを上げます。
5. **保存**を押すと、記事は下書きのステータスで**記事**リストに入ります。

> ヒント: メインキーワードを含むタイトルを書く、わかりやすい見出しで記事を区切る、冒頭の段落で質問に直接答える - これら3つはすべて SEO にも GEO にも効果的です。

---

## 7. 記事の管理

**記事**の項目では、組織内のすべての記事が一覧表示されます。

- **ステータス**(下書き / 公開済み)と**言語**で絞り込みます。
- 記事を開いて、**続けて編集**、**再採点**、**翻訳**、**最適化**、または**公開**を行います。
- スコアの列により、どの記事に改善が必要かをすばやく把握できます。

> 注意: 公開済みの記事を編集して再度公開する場合、同じ連携を通じて公開する限り、ソフトウェアは**ウェブサイト上の元の記事を正しく更新**します(重複記事は作成しません)。

---

## 8. SEO と GEO の最適化

**最適化**の項目では、詳細に採点し、修正すべき箇所を正確に指摘します。

1. 最適化したい記事を選びます。
2. 各基準ごとのスコア表を確認します: タイトル、説明文(meta)、見出し構造、キーワード密度、内部リンク、構造化データ(schema)、AI に引用される可能性など。
3. 「未達成」の各項目には具体的な提案があります。提案を適用してから、スコアが高くなるまで再採点します。

**内部リンクについて**: リンクは**実際に公開された記事**(実在するパスがあるもの)にのみ張るべきです。存在しないページへのリンクは張らないでください。

**外部リンクについて**: 他のウェブサイトへのすべてのリンクは、読者があなたのページから離れないよう、新しいタブで開くようにしてください。

---

## 9. 翻訳と多言語対応

**翻訳**の項目では、ある記事の別言語版を作成できます。

1. 元の記事と、対象言語(1つまたは複数)を選びます。
2. ソフトウェアは機械的に翻訳するのではなく、**ローカライズ**します: 例え、単位、文体を適応させたうえで、現地のキーワードに合わせて SEO/GEO を再最適化します。
3. 翻訳を確認し、必要に応じて調整してから、独立した記事として保存します。

ソフトウェアの画面は複数の言語に対応しています。表示言語はアカウントメニューで変更できます。

---

## 10. 画像: 設定と圧縮

### 10.1. 画像設定(挿絵)

**画像設定**の項目では、記事の画像の生成・挿入方法を指定します: スタイル、比率、SEO 用の代替テキスト(alt)など。

### 10.2. 画像圧縮

**画像圧縮**の項目では、画像の容量を減らし、形式を **WebP/AVIF**(SEO に優しく、読み込みが速い)に変換できます。

1. 画像をアップロードします。
2. 形式と圧縮レベルを選びます。
3. 最適化された画像をダウンロードします。ソフトウェアはその場で処理を行い、あなたの画像を保存することはありません。

---

## 11. 記事の公開

### 11.1. CMS に公開する(WordPress、Wix、Shopify、Haravan、Sapo)

1. **公開**に移動します(または記事を開いて公開を選びます)。
2. 公開先のウェブサイトの**連携**を選びます。
3. タイトル、パス(slug)、説明文、アイキャッチ画像を確認します。
4. **公開**を押します。以前に公開した記事の場合、ソフトウェアは元の記事を正しく**更新**します。

### 11.2. Google Sheet に書き出す

CMS のほかに、記事を **Google Sheet** に送り込むこともできます(例えば別のチームがその後の処理を行う場合など)。Google を一度連携し、対象のスプレッドシートを選ぶと、ソフトウェアが各記事を行ごとに書き込み、slug に基づいて更新します。

### 11.3. 公開スケジュール

**カレンダー**の項目では公開のスケジュールを組めます: 各記事に日時を指定し、まとめて公開するのではなくコンテンツを一定のペースで配信できます。

---

## 12. チェックと監査

- **監査**: あるページ/記事をスキャンして SEO の健全性を採点し、修正すべきエラーを指摘します。
- **ランディング監査(Landing Audit)**: 販売ページ/ランディングページを個別に精査し、タイトル、行動喚起(CTA)、説得のための構成を評価します。

これらの項目を使って、既存のコンテンツ(ソフトウェアで作成していない記事も含む)を見直しましょう。

---

## 13. レポートと引用

- **レポート**: 使用した token 量、AI の費用(あなたの通貨に換算)、プロバイダー/モデル別および担当者別の統計を確認できます。費用の管理に役立ちます。
- **引用(Citations)**: 記事内で引用するための信頼できる情報源を提案し、信頼性と AI に引用される可能性(GEO)を高めます。

---

## 14. タスクと共同作業

組織に複数のメンバーがいる場合は、**マイタスク**の項目を使ってチームで作業します。

- **記事の割り当て**: オーナー/管理者がメンバーに記事の執筆を割り当てます。
- **記事の承認**: 記事は公開前に権限を持つ人による**承認**が必要です。あなたの承認待ちの記事は**マイタスク**に表示されます。
- **コメント**: 各記事上で直接やり取りできます。

権限の割り当て(誰が執筆、公開、承認、連携の管理を行えるか)は、**組織**のページで設定します(第17章を参照)。

---

## 15. お知らせと通知

- **通知ベル**(右上): あなた宛ての更新情報やお知らせです。
- **お知らせ**: ニュースやソフトウェアの使い方のヒントです。**新しい**お知らせには「新着」のラベルが付きます。あるお知らせを開いて読むと、そのラベルは消えます。すばやく消すための**すべて既読にする**ボタンもあります。

## 16. プランと利用上限

**料金プラン**の項目では、現在どのプランに加入しているか、当期の記事作成回数の残り、そして更新日を確認できます。

- 残りの利用上限と履歴を確認できます。
- 上限や機能を追加したいときはプランをアップグレードします。
- アカウントに追加回数(overage)や無制限が付与されている場合も、その情報はここに表示されます。

## 17. アカウント、セキュリティ、組織

### 17.1. アカウント

**アカウント**の項目(メニュー下部のあなたの名前を押します)では、表示名の変更と**パスワードの変更**ができます。パスワードを忘れた場合は、ログインページの「パスワードを忘れた場合」のリンクから、メール経由で再設定してください。

### 17.2. 組織(Biz)

メニュー上部の組織名を押す → **組織の管理**:

- **メンバー**: 組織に人を招待し、役割に応じて権限を割り当てます。
- **ブランドボイス(Brand voice)**: AI がブランドらしく書けるよう、文体を登録します。
- **組織の API token**: 他のシステムがあなたの API を呼び出すためのキーを作成します(開発者向け)。
- **組織の切り替え/新規作成**: 複数のワークスペースを管理します。

## 18. よくある質問(FAQ)

**AI の API キーは必ず必要ですか?**
はい。執筆と採点の機能は AI を使うため、連携の項目に有効な API キーが少なくとも1つ必要です。

**なぜ記事を公開できないのですか?**
次を確認してください: ウェブサイトの連携を追加したか、連携情報が正しいか(連携をテストを押します)、そしてアカウントに**公開**の権限があるか。

**公開済みの記事を編集して再度公開すると、重複記事ができますか?**
いいえ。同じ連携を通じて公開すれば、ソフトウェアは元の記事を正しく更新します。

**SEO/GEO スコアが低い場合、どこで修正しますか?**
**最適化**の項目に移動します。未達成の各基準には具体的な提案があるので、修正してから再採点してください。

**AI の費用はどのように計算されますか?**
利用するプロバイダーの入力/出力 token に基づきます。詳細は**レポート**をご覧ください。

**複数人で一緒に作業したいのですが?**
彼らを**組織**に招待して権限を割り当ててください。**マイタスク**で記事の割り当てと承認のフローを使います。

**画面の言語はどこで変更しますか?**
アカウントメニュー/言語選択で行います。記事の内容の翻訳は**翻訳**の項目で別途行います。

## 19. ソーシャル＆EC レポート（Facebook・Instagram・Threads・TikTok・YouTube・FBグループ・Shopee・TikTok Shop・Lazada）

実データ + AI でソーシャルチャンネル（自社・競合）を 2 フェーズで分析します:

1. **連携管理** → ソーシャルレポート用の**データ収集**キーを追加（そこの案内に従ってください）。収集のたびに結果数に応じたクレジット（通常数セント）を消費。**複数の Apify キー**を追加できます - 保存前にキーをテストし、収集のたびにランダムに1つのキーを使用します（失敗または上限超過のキーは自動的に別のキーへ切り替わります）。
2. **ソーシャルレポート** → **レポート作成** → ポップアップで**チャンネルを選択**: Facebook ページ、TikTok、YouTube、または**総合**（マルチプラットフォーム）。総合は 2 方式: **キーワード/トピック**入力（各プラットフォームの人気コンテンツを自動収集）または**チャンネルリンク**を直接入力。
3. **フェーズ 1 - 生データ収集**: 進捗付きで段階実行（チャンネル情報 → 投稿/動画 → Facebook は Reels/広告 → コメント）し、**収集済み**で停止 - 各チャンネルの生データ + 指標をすぐ確認。
4. **フェーズ 2 - AI 分析**: **分析**をクリック → AI とモデルを選択（または「自動」）→ ブランド・戦術・総括を分析。総合レポートには**チャンネル間比較**と配分提案も。別の AI で**再分析**しても追加収集費用なし。
5. レポート一覧はチャンネルで絞り込み可能。システム内で閲覧、**PDF 書き出し**、**.doc ダウンロード**、**Google Drive に保存**(ロゴ + 出典はシステム情報から)。

6. **ブランドスタイル**: レポートページで**ブランドスタイル**をクリック → AI が投稿/動画からスタイルプロファイル（トーン、呼びかけ方、語彙、文体、論法、型、独自の特徴、特徴フレーズ、すべき/避ける）を抽出 → セクションごとに確認し、**Markdown をコピー/ダウンロード**または**再利用プロンプトをコピー**して他の AI にこのブランドの声で書かせられます。

7. **Facebookグループレポート**: 作成ポップアップで**Facebookグループ**を選び、**公開**グループのリンク（facebook.com/groups/...）を貼り付けます。システムは**投稿と各投稿のコメント**（コメントは投稿に紐づけて一緒に分析）、グループ情報（メンバー数・説明）、指標（投稿頻度・投稿タイプ・注目の投稿メンバー）を収集します。AI がコミュニティ視点で**ホットな話題**、**メンバーインサイト**（ニーズ・悩み・質問・言葉遣い）、**コンテンツ/シーディング機会**と投稿アイデアを分析します。投稿の範囲は**人気**（直近6か月で高エンゲージメント）か**最新**を選べます。非公開グループは分析できません。

8. **Instagram / Threads / Shopee商品**: 作成ポップアップで該当チャネルを選択。Instagramはプロフィールリンクか@username（投稿+Reels（**文字起こし**付き）+コメント）、Threadsは@username（投稿+返信、リポスト/引用指標）、Shopeeは**商品リンク**（...-i.SHOPID.ITEMID）を貼り付け - 商品情報+購入者レビュー（観点別の星、購入バリエーション、ショップ返信付き）を収集し、AIが**リスティング**、**購入者インサイト**（好評/不満、ニーズ、言葉遣い）、**改善提案+販売コンテンツ+FAQ**を分析します。InstagramとThreadsは総合レポートにも参加できます。

9. **Shopeeショップ**: **Shopeeショップ**を選び、ショップリンク（例 shopee.vn/shopname）またはユーザー名を貼り付けます。システムは**ショップ情報**（星・フォロワー・総商品数・返信率）+**商品カタログ**（価格・割引・評価）+**人気商品のレビュー**（各レビューは商品に紐づく）を収集し、AIが**カタログと価格戦略**、**商品横断の顧客インサイト**、**総括と提案**（機会・改善・販売コンテンツ）を分析します。商品レポートと同様にレポート名を任意設定できます。

10. **TikTok Shop**: **TikTok Shop**カード（および**Shopee**カード）は2種類を統合 - クリックすると**商品**か**ショップ全体**かを選択します。商品: 商品リンク（またはvt.tiktok.com共有リンク/商品ID）を貼り付け → 価格・割引・**販売数**・在庫・バリエーション+顧客レビューを収集 → AIがリスティング分析・購入者インサイト・**販売動画**を提案。ショップ: TikTok Shop表示通りの**ショップ名**を入力（公開ショップURLなし）→ 人気商品+総販売数/推定売上+人気商品のレビュー（商品ごとに紐づけ）を収集 → AIがカタログと価格・顧客インサイト・総括を分析。**地域**を正しく選択してください（既定はVN）。

11. **Lazada**: **Lazada**カードも2種類を統合。商品: パスに商品名を含む完全なリンク（またはs.lazada.vn共有リンク）を貼り付け → 1回の実行で価格・割引・**販売数**・セラー+顧客レビューを収集 → AIがリスティング・購入者インサイト・総括を分析。ショップ: ショップリンク（lazada.vn/shop/shopname）を貼り付け → カタログ+商品ごとのレビューを収集 → AIがカタログと価格・顧客・総括を分析。

12. **EC総合**（市場調査）: **総合**カードは**ソーシャル**（従来フロー）か**EC**かを選択するようになりました。EC: **商品/ニッチのキーワード**+地域を入力 → Shopee・TikTok Shop・Lazadaの**売れ筋**商品を収集 → AIが**市場の全体像**（需要・モール別価格）、**モール横断の主要競合**、**総括+参入計画**（優先モール・推奨価格・差別化）を分析。出店前の市場/競合調査に。

13. **ビジュアルチャート**: すべてのレポートは**チャート**セクションで始まります - ソーシャル: 投稿時期別パフォーマンス・トップ投稿・形式・曜日（FBグループは活発メンバーも）; 商品: 星の分布・人気バリエーション; ショップ: 売れ筋・価格分布・星の分布（TikTok Shopは**7日vs30日の販売ペース**を増減で緑/赤表示）; 総合: チャンネル/モール比較チャート。PDF/.doc/Drive出力でもチャートは保持されます。

14. **近日公開**: **Zalo** と **Messenger** チャネルは開発中です - チャネル選択に「Coming soon」タグ付きで表示され、まだ選択できません。準備ができ次第利用可能になります。

プラン制限: 月に作成できるソーシャルレポート数と利用可能なチャネルはアカウント所有者のプランによります。Free プランは Facebook ページのみ分析できます。現在の上限は**料金プラン**ページをご確認ください。Free プランでは、ページのレポートは前半（ターゲット層まで）のみ表示され、PDF/DOC/Drive への書き出しはできません - アップグレードで完全な分析と書き出しが解除されます。

ヒント: 投稿はチャンネルごとに「投稿 1..N」で参照（複数チャンネル時はプラットフォーム名つき）。途中で失敗したら**再試行**で継続。

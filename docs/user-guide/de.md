# Bedienungsanleitung

Dieses Dokument führt Sie von A bis Z durch die Software: von der Erstellung eines Kontos über das Schreiben SEO/GEO-optimierter Artikel bis hin zum Veröffentlichen auf Ihrer Website. Sie brauchen keinerlei technisches Vorwissen, um mitzumachen.

> Tipp: Nutzen Sie das Feld "In der Anleitung suchen" oben auf der Seite, um schnell zum gewünschten Abschnitt zu springen.

> Wo immer Sie während der Nutzung ein (i)-Symbol sehen, klicken Sie darauf, um eine ausführliche Erklärung des Feldes zu lesen.

---

## 1. Schnellstart (3 Schritte)

Nur 3 Schritte, und Sie haben Ihren ersten Artikel:

1. **AI-API-Schlüssel eingeben** - die Software nutzt AI (Claude, OpenAI, Gemini, DeepSeek) zum Schreiben und Bewerten. Sie müssen den API-Schlüssel eines Anbieters unter **Verbindungen** einfügen (siehe Abschnitt 3).
2. **Website verbinden** (nicht sofort erforderlich) - wenn Sie Artikel direkt auf WordPress, Wix, Shopify, Haravan, Sapo oder Google Sheet veröffentlichen möchten, fügen Sie unter **Verbindungen** eine Verbindung hinzu.
3. **Ersten Artikel schreiben** - öffnen Sie den **Editor**, geben Sie ein Thema ein, lassen Sie die AI einen Entwurf erstellen, und bearbeiten und bewerten Sie ihn anschließend.

Auf der Seite **Übersicht** finden Sie eine Checkliste, die Sie an den Abschluss von Schritt 1 und 2 erinnert. Sobald Sie fertig sind, verschwindet die Checkliste automatisch.

---

## 2. Grundlegende Begriffe

- **Organisation (Biz)**: Ihr Arbeitsbereich. Alle Artikel, Verbindungen und Mitarbeiter gehören zu einer Organisation. Sie können mehrere Organisationen anlegen und über das Auswahlfeld mit dem Organisationsnamen oben im linken Menü zwischen ihnen wechseln.
- **Artikel (Article)**: ein Inhalt, den Sie erstellen. Ein Artikel hat den Status **Entwurf** (draft) oder **Veröffentlicht** (published).
- **SEO- / AEO- / GEO-Wert**: drei Maßstäbe für die Qualität eines Artikels:
  - **SEO**: der Grad der Optimierung für Suchmaschinen (Google) - Titel, Beschreibung, Heading-Tags, Keywords, Links.
  - **AEO**: der Grad der Optimierung, um in Antwortboxen (Answer Engine) wie Google AI Overviews zu erscheinen.
  - **GEO**: der Grad der Optimierung, damit AI-Systeme (ChatGPT, Perplexity, Gemini) Ihren Artikel zitieren.
- **Token**: die Einheit, mit der die von der AI verarbeitete Textmenge gemessen wird. "Eingabe-Token" sind die Daten, die Sie an die AI senden, "Ausgabe-Token" ist der von der AI erzeugte Inhalt. Die AI-Kosten werden nach Token berechnet; Details finden Sie unter **Berichte**.
- **Verbindung (Connection)**: eine Anbindung an eine Website/einen Kanal zum Veröffentlichen von Artikeln (WordPress, Wix, Shopify, Haravan, Sapo, Google Sheet).

## 3. Verbindungen: AI-API-Schlüssel und Website

Hier geben Sie alles ein, was die Software zum Funktionieren braucht. Öffnen Sie **Verbindungen** im linken Menü (Gruppe **System**).

### 3.1. AI-API-Schlüssel hinzufügen

Die Software bringt keine AI mit - Sie verwenden Ihren eigenen API-Schlüssel und behalten so Kosten und Limits selbst in der Hand.

1. Öffnen Sie **Verbindungen** → Bereich **AI-API-Schlüssel**.
2. Wählen Sie einen Anbieter: **Claude (Anthropic)**, **OpenAI**, **Gemini (Google)** oder **DeepSeek**.
3. Fügen Sie den API-Schlüssel ein (aus dem Verwaltungsbereich des jeweiligen Anbieters) und **speichern** Sie.
4. Aktivieren Sie den Schalter zum Einschalten. Sie können mehrere Anbieter hinzufügen und den Hauptanbieter auswählen.

> Tipp: Falls Sie noch keinen Schlüssel haben, registrieren Sie ein Konto beim AI-Anbieter, erstellen Sie einen API-Schlüssel und fügen Sie ihn anschließend hier ein. Der Schlüssel wird sicher gespeichert und nach dem Speichern nicht mehr vollständig angezeigt.

### 3.2. Website zum Veröffentlichen verbinden

1. Öffnen Sie **Verbindungen** → Bereich **Website-Verbindungen** → **Verbindung hinzufügen**.
2. Wählen Sie die Plattform: **WordPress, Wix, Shopify, Haravan, Sapo**.
3. Folgen Sie den Anweisungen, die direkt im Fenster für die jeweilige Plattform erscheinen (Website-Adresse, Konto/Anwendungspasswort oder Token eingeben).
4. Klicken Sie auf **Verbindung testen**, um sicherzustellen, dass die Angaben korrekt sind, und **speichern** Sie dann.

Nach dem Verbinden können Sie Artikel direkt aus der Software veröffentlichen oder aktualisieren (siehe Abschnitt 11).

## 4. Keyword-Recherche

Der Bereich **Keywords** hilft Ihnen, vor dem Schreiben Keywords zu finden und zu gruppieren, damit der Artikel genau dem Bedarf der Suchenden entspricht.

1. Öffnen Sie **Keywords** und geben Sie ein Ausgangs-Keyword ein (Beispiel: "Laufschuhe").
2. Die Software schlägt einen Satz verwandter Keywords vor, samt Suchintention und häufig gestellten Fragen (im GEO-Stil).
3. Wählen Sie passende Keywords aus und speichern Sie sie als Keyword-Satz für den Planungsschritt.

> Tipp: Achten Sie auf die Spalte Intention (intent). Keywords wie "kaufen/Preis" passen zu Verkaufsartikeln; Keywords wie "wie/was ist" passen zu Ratgeberartikeln.

---

## 5. Content-Planung

Der Bereich **Plan** verwandelt einen Keyword-Satz in eine Liste zu schreibender Artikel, mit vorgeschlagenen Titeln und Gliederungen.

1. Öffnen Sie **Plan** und wählen Sie einen Keyword-Satz oder geben Sie ein Thema ein.
2. Die Software schlägt Titel und Gliederungen (outline) vor.
3. Prüfen, bearbeiten und übertragen Sie dann die einzelnen Einträge in den **Editor** zum Schreiben.

So bauen Sie systematisch einen Themencluster (topic cluster) auf, statt einzelne Artikel unzusammenhängend zu schreiben.

---

## 6. Editor (Artikel schreiben)

Der Bereich **Editor** ist der Ort, an dem Sie Artikel schreiben und fertigstellen.

1. Geben Sie **Titel** und **Ziel-Keyword** ein.
2. Klicken Sie, damit die AI einen **Entwurf** zum Thema erstellt. Sie können auch selbst schreiben oder vorhandene Inhalte einfügen.
3. Nutzen Sie die Hilfswerkzeuge:
   - **Umschreiben / Erweitern / Kürzen** eines Absatzes.
   - **Vermenschlichen (humanize)**: macht den Text natürlicher und weniger maschinell.
   - **Faktencheck (fact-check)**: prüft Angaben, die leicht fehlerhaft sein können.
   - **Bild einfügen**: erzeugt Bilder oder schlägt Bilder vor (siehe Abschnitt 10).
4. Sehen Sie die **SEO- / AEO- / GEO-Werte** in Echtzeit und folgen Sie den Empfehlungen, um die Werte zu verbessern.
5. Klicken Sie auf **Speichern** - der Artikel landet in der Liste **Artikel** mit dem Status Entwurf.

> Tipp: Schreiben Sie einen Titel mit dem Haupt-Keyword, gliedern Sie den Artikel mit klaren Headings und beantworten Sie die Frage direkt im ersten Absatz - alle drei sind gut für SEO und GEO.

---

## 7. Artikel verwalten

Der Bereich **Artikel** listet alle Artikel der Organisation auf.

- Filtern Sie nach **Status** (Entwurf / Veröffentlicht) und **Sprache**.
- Öffnen Sie einen Artikel, um ihn **weiterzubearbeiten**, **erneut zu bewerten**, zu **übersetzen**, zu **optimieren** oder zu **veröffentlichen**.
- Die Wertespalte zeigt Ihnen schnell, welcher Artikel verbessert werden muss.

> Hinweis: Wenn Sie einen bereits veröffentlichten Artikel bearbeiten und erneut veröffentlichen, **aktualisiert die Software den richtigen alten Artikel auf der Website** (ohne Duplikate zu erstellen), sofern Sie über dieselbe Verbindung veröffentlichen.

---

## 8. SEO und GEO optimieren

Der Bereich **Optimieren** bewertet detailliert und zeigt genau, was verbessert werden muss.

1. Wählen Sie den zu optimierenden Artikel.
2. Sehen Sie die Bewertungstabelle nach Kriterien: Titel, Beschreibung (Meta), Heading-Struktur, Keyword-Dichte, interne Verlinkung, strukturierte Daten (Schema), Wahrscheinlichkeit, von AI zitiert zu werden ...
3. Jeder Punkt "nicht erfüllt" hat eine konkrete Empfehlung. Wenden Sie die Empfehlung an und bewerten Sie erneut, bis der Wert hoch ist.

**Zur internen Verlinkung**: Verlinken Sie nur auf Artikel, die **tatsächlich veröffentlicht** sind (mit einer echten URL). Setzen Sie keine Links zu Seiten, die noch nicht existieren.

**Zu externen Links**: Jede URL zu einer anderen Website sollte in einem neuen Tab öffnen, damit der Leser Ihre Seite nicht verlässt.

---

## 9. Übersetzung und Mehrsprachigkeit

Der Bereich **Übersetzungen** hilft dabei, eine anderssprachige Version eines Artikels zu erstellen.

1. Wählen Sie den Ausgangsartikel und die Zielsprache(n).
2. Die Software übersetzt nicht mechanisch, sondern **lokalisiert**: Sie passt Beispiele, Einheiten und Schreibstil an und optimiert anschließend SEO/GEO nach lokalen Keywords neu.
3. Prüfen Sie die Übersetzung, passen Sie sie bei Bedarf an und speichern Sie sie als eigenen Artikel.

Die Software-Oberfläche unterstützt mehrere Sprachen; die Anzeigesprache ändern Sie im Kontomenü.

## 10. Bilder: Einstellungen und Komprimierung

### 10.1. Bildeinstellungen (Illustrationsbilder)

Der Bereich **Bildeinstellungen** legt fest, wie Bilder für den Artikel erzeugt und eingefügt werden: Stil, Seitenverhältnis, Alternativtext (Alt) für SEO.

### 10.2. Bildkomprimierung

Der Bereich **Bildkomprimierung** hilft, die Dateigröße von Bildern zu verringern und das Format in **WebP/AVIF** umzuwandeln (SEO-freundlich, schnelleres Laden).

1. Laden Sie ein Bild hoch.
2. Wählen Sie Format und Komprimierungsstufe.
3. Laden Sie das optimierte Bild herunter. Die Software verarbeitet es direkt und speichert Ihre Bilder nicht.

## 11. Artikel veröffentlichen

### 11.1. Auf einem CMS veröffentlichen (WordPress, Wix, Shopify, Haravan, Sapo)

1. Öffnen Sie **Veröffentlichen** (oder öffnen Sie den Artikel und wählen Sie Veröffentlichen).
2. Wählen Sie die Ziel-**Verbindung** zur Website.
3. Prüfen Sie Titel, URL (slug), Beschreibung und Titelbild.
4. Klicken Sie auf **Veröffentlichen**. Handelt es sich um einen zuvor veröffentlichten Artikel, **aktualisiert** die Software den richtigen alten Artikel.

### 11.2. In ein Google Sheet veröffentlichen

Neben dem CMS können Sie Artikel in ein **Google Sheet** übertragen (zum Beispiel, damit ein anderes Team sie weiterverarbeitet). Verbinden Sie Google einmalig, wählen Sie die Ziel-Tabelle, und die Software schreibt jeden Artikel zeilenweise und aktualisiert ihn anhand des Slug.

### 11.3. Veröffentlichungsplan

Der Bereich **Kalender** ermöglicht es, Veröffentlichungen zu planen: Legen Sie für jeden Artikel Datum und Uhrzeit fest, damit Inhalte gleichmäßig erscheinen, statt geballt.

## 12. Prüfung und Audit

- **Audit**: scannt eine Seite/einen Artikel, um die SEO-Gesundheit zu bewerten und zu behebende Fehler aufzuzeigen.
- **Landing-Prüfung (Landing Audit)**: prüft gezielt Verkaufs-/Landingpages und bewertet Titel, Handlungsaufforderung (Call-to-Action) und überzeugende Struktur.

Nutzen Sie diese Bereiche, um vorhandene Inhalte nachzuprüfen (auch Artikel, die nicht mit der Software erstellt wurden).

---

## 13. Berichte und Zitate

- **Berichte**: zeigt die verbrauchten Token, die AI-Kosten (umgerechnet in Ihre Währung), Statistiken nach Anbieter/Modell und nach Mitarbeiter. Dient der Kostenkontrolle.
- **Zitate (Citations)**: schlägt vertrauenswürdige Quellen zum Zitieren im Artikel vor, was die Glaubwürdigkeit und die Wahrscheinlichkeit erhöht, von AI zitiert zu werden (GEO).

## 14. Aufgaben und Zusammenarbeit

Wenn Ihre Organisation aus mehreren Personen besteht, nutzen Sie den Bereich **Meine Aufgaben** für die Teamarbeit:

- **Artikel zuweisen**: Inhaber/Manager weisen Mitarbeitern Artikel zum Schreiben zu.
- **Artikel freigeben**: Ein Artikel muss von einer berechtigten Person **freigegeben** werden, bevor er veröffentlicht wird. Artikel, die auf Ihre Freigabe warten, erscheinen unter **Meine Aufgaben**.
- **Kommentare**: tauschen Sie sich direkt an jedem Artikel aus.

Die Rechtevergabe (wer schreiben, veröffentlichen, freigeben, Verbindungen verwalten darf ...) erfolgt auf der Seite **Organisation** (siehe Abschnitt 17).

## 18. Häufig gestellte Fragen (FAQ)

**Muss ich zwingend einen AI-API-Schlüssel haben?**
Ja. Die Funktionen zum Schreiben und Bewerten nutzen AI, daher wird mindestens ein gültiger API-Schlüssel im Bereich Verbindungen benötigt.

**Warum lässt sich mein Artikel noch nicht veröffentlichen?**
Prüfen Sie: Haben Sie bereits eine Website-Verbindung hinzugefügt, sind die Verbindungsdaten noch korrekt (klicken Sie auf Verbindung testen), und hat das Konto die Berechtigung zum **Veröffentlichen**?

**Erzeugt das Bearbeiten und erneute Veröffentlichen eines bereits veröffentlichten Artikels ein Duplikat?**
Nein. Die Software aktualisiert den richtigen alten Artikel, wenn Sie über dieselbe Verbindung veröffentlichen.

**Wo verbessere ich einen niedrigen SEO/GEO-Wert?**
Öffnen Sie den Bereich **Optimieren**: Jedes nicht erfüllte Kriterium hat eine konkrete Empfehlung, die Sie umsetzen und anschließend erneut bewerten können.

**Wie werden die AI-Kosten berechnet?**
Nach den Eingabe-/Ausgabe-Token des von Ihnen genutzten Anbieters. Details finden Sie unter **Berichte**.

**Ich möchte mit mehreren Personen zusammenarbeiten?**
Laden Sie sie in die **Organisation** ein und vergeben Sie Rechte. Nutzen Sie den Ablauf Artikel zuweisen - Artikel freigeben unter **Meine Aufgaben**.

**Wo ändere ich die Sprache der Oberfläche?**
Im Kontomenü/Sprachauswahl. Der Inhalt von Artikeln wird separat im Bereich **Übersetzungen** übersetzt.

## 19. Social- & E-Commerce-Report (Facebook, Instagram, Threads, TikTok, YouTube, FB-Gruppen, Shopee, TikTok Shop, Lazada)

Analysieren Sie Social-Kanäle (eigene oder Wettbewerber) mit echten Daten + KI, in 2 Phasen:

1. Gehen Sie zu **Verbindungen** → fügen Sie den **Datenerfassungs**-Key für Social-Report hinzu (folgen Sie den dortigen Hinweisen). Jede Erfassung verbraucht Guthaben je nach Ergebnissen (meist wenige Cent). Sie können **mehrere Apify-Keys** hinzufügen - jeder Key wird vor dem Speichern getestet, und jede Erfassung wählt zufällig einen Key (ein fehlgeschlagener oder erschöpfter Key wechselt automatisch zu einem anderen).
2. Öffnen Sie **Social-Report** → **Report erstellen** → ein Popup lässt Sie den **Kanal wählen**: Facebook-Seite, TikTok, YouTube oder **Gesamt** (Multi-Plattform). Gesamt hat 2 Modi: **Keyword/Thema** eingeben (das System findet Top-Inhalte je Plattform automatisch) oder direkt **Kanal-Links** eingeben.
3. **Phase 1 - Rohdaten erfassen**: läuft Schritt für Schritt mit Fortschritt (Kanalinfos → Beiträge/Videos → bei Facebook Reels/Anzeigen → Kommentare) und stoppt bei **Daten erfasst** - Rohdaten + Kennzahlen je Kanal sofort einsehbar.
4. **Phase 2 - KI-Analyse**: **Analysieren** klicken → KI und Modell wählen (oder „Auto") → die KI analysiert Marke, Taktiken, Zusammenfassung; der Gesamt-Report ergänzt den **Kanalvergleich** und Verteilungsempfehlungen. **Neu analysieren** mit anderer KI ohne zusätzliche Erfassungskosten.
5. Die Report-Liste lässt sich nach Kanal filtern; im System ansehen, **PDF exportieren**, **.doc herunterladen** oder **in Google Drive speichern** (Logo + Quelle aus Systeminfo).

6. **Markenstil**: Klicken Sie auf der Report-Seite auf **Markenstil** → die KI extrahiert ein Stilprofil aus den Beiträgen/Videos (Tonalität, Ansprache, Wortschatz, Satzmuster, Argumentation, Formeln, Erkennungsmerkmale, Signature-Phrasen, Tun/Vermeiden) → abschnittsweise prüfen und **Markdown kopieren/herunterladen** oder **wiederverwendbaren Prompt kopieren**, damit eine andere KI in dieser Markenstimme schreibt.

7. **Facebook-Gruppen-Report**: Wählen Sie im Erstellungs-Popup **Facebook-Gruppe** und fügen Sie den Link einer **öffentlichen** Gruppe ein (facebook.com/groups/...). Das System sammelt **Beiträge samt Kommentaren je Beitrag** (Kommentare bleiben ihrem Beitrag zugeordnet und werden gemeinsam analysiert), Gruppeninfos (Mitgliederzahl, Beschreibung) und Kennzahlen (Frequenz, Beitragstypen, aktivste Beitragende). Die KI analysiert aus Community-Sicht: **heiße Themen**, **Mitglieder-Insights** (Bedürfnisse, Schmerzpunkte, Fragen, Sprache) und **Content-/Seeding-Chancen** mit Beitragsideen. Umfang wählbar: **Top** (letzte 6 Monate) oder **Neueste**. Private Gruppen können nicht analysiert werden.

8. **Instagram / Threads / Shopee-Produkt**: Wählen Sie den Kanal im Erstellungs-Popup. Instagram nimmt einen Profillink oder @username (Beiträge + Reels mit **Transkripten** + Kommentare); Threads nimmt @username (Beiträge + Antworten, Repost-/Zitat-Kennzahlen); Shopee nimmt einen **Produktlink** (...-i.SHOPID.ITEMID) - das System sammelt Produktinfos + Kundenbewertungen (mit Aspekt-Sternen, gekaufter Variante, Verkäuferantworten), dann analysiert die KI das **Listing**, **Käufer-Insights** (Lob/Kritik, Bedürfnisse, Sprache) und **Verbesserungsvorschläge + Verkaufscontent + FAQ**. Instagram und Threads können auch am Gesamtbericht teilnehmen.

9. **Shopee-Shop**: Wählen Sie **Shopee-Shop**, fügen Sie den Shop-Link (z. B. shopee.vn/shopname) oder Benutzernamen ein. Das System sammelt **Shop-Infos** (Sterne, Follower, Produktanzahl, Antwortquote) + **Produktkatalog** (Preis, Rabatt, Bewertung) + **Bewertungen der Top-Produkte** (jede Bewertung ihrem Produkt zugeordnet); die KI analysiert **Katalog- & Preisstrategie**, **produktübergreifende Kunden-Insights** und **Fazit & Vorschläge** (Chancen, Verbesserungen, Verkaufscontent). Optionaler Berichtsname wie beim Produktbericht.

10. **TikTok Shop**: Die **TikTok Shop**-Karte (und die **Shopee**-Karte) bündelt beide Typen - beim Klick wird gefragt, ob der Bericht ein **Produkt** oder den **ganzen Shop** betrifft. Produkt: Produktlink (oder vt.tiktok.com-Kurzlink / Produkt-ID) einfügen → Preis, Rabatt, **Verkäufe**, Bestand, Varianten + Kundenbewertungen → KI analysiert das Listing, Käufer-Insights und schlägt **Verkaufsvideos** vor. Shop: **Shop-Namen** genau wie auf TikTok Shop eingeben (keine öffentliche Shop-URL) → System findet Top-Produkte + Gesamtverkäufe/gesch. Umsatz + Bewertungen der Top-Produkte (je Produkt zugeordnet) → KI analysiert Katalog & Preise, Kunden-Insights und Fazit. Wählen Sie die richtige **Region** (Standard VN).

11. **Lazada**: Die **Lazada**-Karte bündelt ebenfalls beide Typen. Produkt: VOLLSTÄNDIGEN Link mit Produktnamen im Pfad (oder s.lazada.vn-Share-Link) einfügen → ein Lauf sammelt Preis, Rabatt, **Verkäufe**, Verkäufer + Kundenbewertungen → KI analysiert Listing, Käufer-Insights und Fazit. Shop: Shop-Link (lazada.vn/shop/shopname) einfügen → Katalog + Bewertungen je Produkt → KI analysiert Katalog & Preise, Kunden und Fazit.

12. **E-Commerce-Gesamtbild** (Marktforschung): Die **Gesamtbild**-Karte fragt jetzt nach **Social** (bestehender Ablauf) oder **E-Commerce**. E-Commerce: **Produkt-/Nischen-Keyword** + Region eingeben → das System sammelt **Bestseller** auf Shopee, TikTok Shop und Lazada → KI analysiert das **Marktbild** (Nachfrage, Preise je Marktplatz), **Top-Wettbewerber** und ein **Fazit + Markteintrittsplan** (Prioritäts-Marktplatz, Preisempfehlung, Differenzierung). Ideal vor dem Verkaufsstart.

13. **Visuelle Diagramme**: Jeder Bericht beginnt mit einem **Diagramm**-Abschnitt - Social: Performance nach Zeitpunkt, Top-Beiträge, Formate, Wochentag (FB-Gruppen: aktivste Mitglieder); Produkte: Bewertungsverteilung, Top-Varianten; Shops: Bestseller, Preisverteilung, Bewertungen (TikTok Shop zusätzlich **Verkaufstempo 7 vs. 30 Tage**, grün/rot je nach Richtung); Gesamtbilder: Kanal-/Marktplatzvergleich. Diagramme bleiben in PDF/.doc/Drive-Exporten erhalten.

14. **Demnächst verfügbar**: Die Kanäle **Zalo** und **Messenger** sind in Entwicklung - sie erscheinen in der Kanalauswahl mit dem Tag „Coming soon" und sind noch nicht auswählbar. Sie werden freigeschaltet, sobald sie bereit sind.

Tariflimits: Die Anzahl der Social-Reports pro Monat und die verfügbaren Kanäle hängen vom Tarif des Kontoinhabers ab; der Free-Tarif kann nur Facebook-Seiten analysieren. Ihre aktuellen Limits finden Sie auf der **Tarifseite**. Im Free-Tarif zeigen Seiten-Berichte nur den ersten Teil (bis zur Zielgruppe) und können nicht als PDF/DOC/Drive exportiert werden - upgraden Sie für die vollständige Analyse und Exporte.

Tipp: Beiträge werden je Kanal als „Beitrag 1..N" referenziert (bei mehreren Kanälen mit Plattformnamen); bei Fehlern **Erneut versuchen**.

## 20. Videoskript-Analyse

Der Bereich **Skript-Analyse** (linkes Menü) zerlegt ein virales Video/Reel, damit Sie dessen Formel lernen und auf Ihre eigenen Inhalte anwenden können.

1. Fügen Sie einen **Videolink** ein (TikTok, YouTube oder Facebook), wählen Sie eine **KI** und ein **Modell** (oder belassen Sie „Auto") und klicken Sie auf **Analysieren**.
2. Das System erkennt die Plattform → holt das Transkript → die KI zerlegt es: **Zusammenfassung**, **Inhaltstyp**, **Zielgruppe**, **Eröffnungs-Hook** (und warum er funktioniert), **Formel/Struktur**, **Sekunde-für-Sekunde-Timeline**, **Tonalität**, **Tempo**, **Stärken**, **Verbesserungen** und **anwendbare Erkenntnisse**.
3. Die Ergebnisse erscheinen direkt auf der Seite, mit dem **eingebetteten Video** neben der Timeline, sodass Sie zugleich lesen und schauen können. Jeder Teil ist ein Block zum Aufklappen.
4. Jede Analyse wird darunter im **Verlauf** gespeichert; klicken Sie auf **Öffnen**, um sie erneut zu öffnen, oder auf **Löschen**.
5. Falls eine **fehlschlägt**, können Sie **KI + Modell erneut wählen** und erneut analysieren (das bereits geholte Transkript wird wiederverwendet — kein erneuter Download).

> Erfordert einen **Datenerfassungs**-Key (Apify), wie beim Social-Report, um das Transkript zu holen. Der Zugriff hängt von Ihrem Tarif ab.

Um eine Analyse extern zu teilen, siehe **Öffentliches Teilen** (Abschnitt 21).

## 21. Öffentliches Teilen (Freigabelink, Passwort, Titelbild)

Sowohl **Social-Reports** als auch **Skript-Analysen** können einen **öffentlichen Freigabelink** erzeugen — Betrachter öffnen einfach den Link und sehen den Inhalt als schreibgeschützte Webseite, **ohne Anmeldung**. (Öffentliche Inhalte folgen weiterhin dem Tarif des Inhabers.)

**Link erstellen:** Öffnen Sie einen fertigen Report/eine fertige Analyse → Bereich **Öffentliches Teilen** → klicken Sie auf **Freigabelink erstellen**. Das System bereitet vor:
- Einen **blog-artigen Kurzlink** (z. B. `.../bao-cao-...` oder `.../kich-ban-...`) zum Posten in sozialen Medien — dies ist der Link zum Kopieren und Teilen.
- Sobald ein Link existiert, **klappt dieser Bereich automatisch zu**; klicken Sie auf **Aufklappen**, um zu bearbeiten.

**Titelbild (Open Graph):** damit beim Einfügen des Links auf Facebook/Zalo eine schöne Vorschau mit Bild + Titel + Beschreibung erscheint.
- **Mit KI erzeugen**: Bildbeschreibung eingeben (optional), Bild-KI/-Modell wählen, auf **KI-Titelbild erzeugen** klicken.
- Oder **Bild hochladen** von Ihrem Gerät — das System komprimiert und formatiert es leicht und social-tauglich um.
- Leer lassen = das Standardbild verwenden (Kanal-Avatar/Logo).

**Passwortsperre:** um die Betrachter einzuschränken → ein **Passwort** festlegen. Wer den Link öffnet, muss das richtige Passwort eingeben, um den Inhalt zu sehen (Titelbild/Titel werden beim Teilen weiterhin angezeigt). Sie können jederzeit das **Passwort ändern** oder die **Sperre entfernen** (wieder öffentlich machen).

**Links verwalten:** Der **Social-Report** (und die **Skript-Analyse**) hat einen Tab **Freigabelinks**, der jeden erstellten Link auflistet: **Kopieren**, **Öffnen**, Titel/Beschreibung/Bild **Bearbeiten**, **Passwort** setzen/entfernen, **Widerrufen** (vorübergehend deaktivieren) oder **Löschen**. Nach dem Widerrufen/Löschen funktioniert der alte Link nicht mehr.

## 22. Bildbibliothek

Der Bereich **Bildbibliothek** (linkes Menü) sammelt jedes Bild, das im gesamten System von der KI erstellt oder hochgeladen wurde.

- **Ansehen** aller Bilder in einem Raster.
- Ein Bild **Umbenennen** oder **Löschen**.
- **Mehrere auswählen**, um sie stapelweise zu löschen — beim Löschen vieler Bilder müssen Sie **DELETE** eingeben, um zu bestätigen (um Versehen zu vermeiden).
